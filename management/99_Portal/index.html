[MINOR] v1.17.0 - 端末をまたぐ「サロンの置き場」の新設と Cloudflare Pages への移設 (ISSUE-026)

カルテが端末の localStorage にしか無く、パソコンで書いたものがスマホで見られない状態を解消しました。OneDrive（Entra のアプリ登録が必要）とフォルダ同期（File System Access API がスマホに無い）はいずれも成立しなかったため、「サロン側でアカウントを作る・アプリを登録する」という前提そのものを外し、合言葉を1回入れるだけでつながる置き場を新設しています。合言葉から PBKDF2（SHA-256・210,000回）で512ビットを作り、前半を AES-GCM の鍵（端末から出ない）、後半を照合値（これだけ送る）として使い分けるため、サーバーを預かる側にも中身は読めません。窓口は Cloudflare Pages Functions + R2 で用意し、照合は timingSafeEqual、Cache-Control: no-store を付与しています。Vercel Hobby は規約で個人・非商用に限られ「予告なく停止できる」と明記されているため、商用利用が認められている Cloudflare へ移設しました。限界として、合言葉を忘れると誰にも読めず、消したことは相手側に伝わりません。
