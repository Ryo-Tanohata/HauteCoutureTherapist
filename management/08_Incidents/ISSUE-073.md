# ISSUE-073: 🕐「施術日・回数」を、📋 カルテへ寄せた

## 概要
- **発生日**: 2026-08-14
- **分類**: 要望（サロンからのご要望）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> その前にこの2つを統合したいです。理由は機能的には全く同じだからです。
> カルテの方を残して、カルテにも施術日・回数のような回数をわかりやすく表示したいです。

ISSUE-072 で**中身を同じ部品にした**結果、2つのタブの違いは
**帯と見出しだけ**になっていました。その状態のスクリーンショットを見て、
サロンから「同じなら1つでよい」とのご判断です。

ISSUE-072 の申し送りに書いた**案B**が、ここで実施されたことになります。

## 直したこと

### ① 🕐 のタブを外し、📋 を先頭・既定にした

タブは **6つ → 5つ**。

```
📋 カルテ ／ 🗓️ カレンダー ／ 💴 金額 ／ 👤 情報 ／ ✨ 星
```

カルテを開いたとき、最初に出るのも 📋 になりました。

### ② 🕐 で見ていたものを、そのまま 📋 に載せた

**消したのではなく、寄せています。**

- **見出し** … 通算施術回数 ／ 最終施術日（＋N日前） ／ 平均施術ペース
- **各カードの帯** … `第 N 回` ／ 来店日時 ／ `前回来店から N 日ぶり`（初回は `🎉 初回来店`）

もとの 📋 の帯は「来店日 ／ 日時」でした。**第N回のほうが分かりやすい**ので、
そちらに置き換えています。

### ③ 古い呼び名でも白紙にならないようにした

```js
if (activeTab === 'visit-count') activeTab = 'visit-type';
```

`switch` に `default` が無いため、外した呼び名で来ると**何も出ない画面**になります。
説明動画の台本など、外から名前で指しているものが残っていた場合の受け皿です。

### ④ 説明動画の台本を直した

`2-8 しばらく来ていない方を探す` が、無くなったタブを押しに行っていました。
**押す相手が消えると黙って飛ばされる**（ISSUE-069）ので、動画を録り直すまで
気づけない形です。台本を 📋 に向け直しました。

### ⑤ 見出しの直書きを CSS へ出した

`.visit-stats` ほか。明るさのスライダーと光のテーマに追随します。
