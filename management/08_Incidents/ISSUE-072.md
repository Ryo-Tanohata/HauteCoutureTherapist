# ISSUE-072: 🕐・📋・💴 が、同じものを3通りに書き分けていた

## 概要
- **発生日**: 2026-08-13
- **分類**: 要望（サロンの画面から発見）
- **状態**: **対応済み（案A）**
- **担当**: Claude Code

## 症状 / 要望

> 現在、施術日の表記が1枚目ですが、2枚目のカルテの表記にしたいです。
> また、この2つは表記が同じで機能が重複しているように見えるので、
> 統合を意識してどのような機能を残して何を表示するかを明確にしたいです。

## 調べたこと

記録が並ぶ場所は**4か所**ありました（📅 の月ぶんカードを含む）。

| | そのタブだけが持っていたもの | 下に並ぶカード |
|---|---|---|
| 🕐 施術日 | 通算回数・最終来店・経過日数・平均ペース／第N回・N日ぶり | 訴え・施術内容・金額 |
| 📋 カルテ | （見出しなし） | ＋ 選んだ色・処方・メモ・区分ごとのカルテ・写真・上書きの控え |
| 💴 金額 | 累計お支払い額・平均客単価 | 施術内容・金額のみ（**たためない**） |
| 📅 カレンダー | 月のマス目 | その月ぶんの簡易カード |

**📋 のカードは 🕐 の上位互換**でした。
🕐 が独自に持っていたのは「第N回」と「N日ぶり」の2つ、
💴 が独自に持っていたのは見出しの2つの数字だけ。
**カードを3通りに書き分ける理由が、実質ありませんでした。**

書き分けの代償は、既に出ていました。**🕐 の金額だけが生の数値から
組み立てられていて**、未入力が「金額未定」と出ていませんでした（ISSUE-070 で発見）。
**片方だけ古くなる**、そのままの形です。

## 直したこと（案A）

サロンにお選びいただいた案です。**タブの数は変えず**、カードを1種類にしました。

### ① 記録カードを1つの部品にした

`createRecordCard(customer, record, { headHtml, extraClass, open, hideSummaryAmount })`

**タブごとに違うのは、カードの頭に載る帯だけ**になりました。

| タブ | 帯 |
|---|---|
| 🕐 | 第N回 ／ 来店日時 ／ N日ぶり |
| 📋 | 来店日 ／ 日時 |
| 💴 | 来店日時 ／ 金額（大きく） |

これで 🕐 でも、**選んだ色・処方・メモ・区分ごとのカルテ・写真・上書きの控え**が
出るようになりました（サロンのご指定で、伏せた項目はありません）。

### ② 💴 もたためるようにした

ここだけ全部開いたままで、押しても閉じませんでした。
帯に金額を大きく出しているので、**要約側の金額は省いています**。

### ③ 開いたら、たたんだ側の1行を消した

同じ文が二重に出ていました（たたんだ側の1行と、開いた中の「訴え:」）。

```css
.history-item.is-open .history-summary-line { display: none; }
```

### ④ 直書きの見た目を、CSS へ出した

`第N回` の帯・`N日ぶり`・💴 の金額・見に来た日の光り方は、
1件ずつ `style="..."` に書かれていました。クラスにしています
（**明るさのスライダーや光のテーマに追随する**ようになります）。

## 検証結果

`management/09_Verification/verify-accordion.js`（第3.5・3.6節を追加）

```
=== 3.5 🕐・📋・💴 が、同じカードを使っているか
   visit-count : 選んだ色/訴え/処方/メモ
   visit-type  : 選んだ色/訴え/処方/メモ
   visit-amount: 選んだ色/訴え/処方/メモ
  3つとも、たためるカードになっている        ✅
  3つとも、同じ欄が開いた中に出る            ✅
  📋 が持っていた欄が、そろって出ている      ✅
=== 3.6 開いたら、たたんだ側の1行が消えるか
  たたんでいる間は要約が出ている              ✅
  開くと要約は引っ込む                        ✅
  開いた中には全文が出ている                  ✅
  ぜんぶ通りました
```

**「同じ部品を使っているか」ではなく「同じ中身が出るか」で見ています。**
部品の名前を見るだけなら、中身が違っても通ってしまいます。

戻りがないことも確認済みです。
`verify-booking` / `verify-cautions` / `verify-csp` / `verify-chat-toggle` /
`verify-clash` / `verify-sticky-tabs` / `verify-demos` / `verify-manual` — **すべて通過**。

## 申し送り

- **記録カードを直すときは `createRecordCard()` だけを直すこと。**
  3か所に散っていたのを1つにまとめたので、ここが唯一の場所です
- **📅 の月ぶんカードだけは、まだ別物**です。あちらは一覧の中の要約で、
  押すとカルテへ飛ぶ作りなので、同じ部品にはしていません
- **案B（🕐 📋 💴 を「記録」1つに統合し、タブを6→4にする）は未実施**です。
  中身は既に同じなので、**あとから移れます**。
  移るとしたら、上に3つの数字（通算回数・最終来店・累計額）を常に出す形
- 💴 の「累計お支払い額」は `Number(r.amount) || 0` で足しています。
  **金額未定のぶんは 0 として数えます**（未定を除いた合計ではありません）
