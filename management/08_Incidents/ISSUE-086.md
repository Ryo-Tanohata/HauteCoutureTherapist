# ISSUE-086: 選んでいる途中で、何を選んだか見えなくなる

## 概要
- **発生日**: 2026-08-21
- **分類**: 不具合（サロンの画面から発見）
- **状態**: **対応済み（配信前）**
- **担当**: Claude Code

## 症状

> 選んでいる時に何を選んでいるかわからなくなるので選んだ時のアイコンだけでいいので
> それか減ったとなって施術のアイコンを下にスクロールしても選んだものは見れるように
> してください

施術内容のアイコンは16個あります。下のほうを見ようとスクロールすると、
**要約の行（選んだ中身と合計）が画面の上へ出てしまい**、
いま何を選んでいるかが分からなくなっていました。

ISSUE-085 で「閉じたままでも中身が分かるように」要約の行を作りましたが、
**開いている間のことを詰めていませんでした。**

## 直したこと

### ① 要約の行を、上に貼り付けた

`.menu-fold > summary { position: sticky; top: 0; }`

選ぶところを下まで送っても、要約の行は**入れ物の上端に貼り付いたまま**残ります。

- `.menu-fold` の `overflow: hidden` を外しました。**あると貼り付けが効きません**
- 貼り付ける以上、地は**必ず不透明**にすること（`var(--bg-base)`）。
  透けると、下のアイコンと文字が重なって読めなくなります
- 角の丸めは `summary` と本体の側に付け直しました

### ② 行の中身を、アイコンだけにした

名前まで出すと、**3つ選べば入りきらず「…」で切れて**いました。
サロンからも「選んだ時のアイコンだけでいい」とのご指示です。

名前は `title` と、読み上げ用の字（`.menu-sr`）に持たせてあります。
アイコンだけでは、目で見ない方に何も伝わらないためです。

## 検証結果

`management/09_Verification/verify-categories.js` の「2.5」と「5」

| 見たこと | 結果 |
|---|---|
| 選ぶところを下まで送っても、要約の行が上に貼り付いて残る（予約） | ✅ |
| 同じくカルテ側でも残る | ✅ |
| 貼り付いた行に、選んだアイコンと合計が出ている | ✅ |
| **貼り付けを外すと上へ抜ける**（見張りが効いている証し） | ✅ |

数字で言うと、カルテ側は**貼り付けがあると 211px（入れ物の上端ちょうど）、
外すと 73px（入れ物の外）**。

あわせて `verify-booking` / `verify-demos` / `verify-manual` / `verify-preview-bundle` /
`verify-card-rows` / `verify-clash` / `verify-accordion` も通ることを確認しました。

## 気づいたこと

- **`overflow: hidden` は `position: sticky` を殺す。** 角を丸めるために付けていた
- **測る位置を間違えると、判定にならない。**
  最初は「アイコンの下端まで送ったとき」で測っていたが、
  そこでは貼り付けが無くても要約が見えていて、外しても ✅ のままだった。
  **「選ぶところを下まで見終えたとき」**（合計や⚙️が見える所）で測ると差が出る
- **入れ子のスクロールに注意。** カルテ側は `#record-form`（495px）と
  `.modal-content`（717px）が二重になっている。画面の一番下まで送ると
  選ぶところ自体を通り過ぎるので、要約が付いてこなくて当たり前になる
  （貼り付けは自分の箱の中までしか効かない）
- **予約の画面では、この位置でも貼り付けが要らなかった。**
  入れ物のほうが高いため。**見張りの証明はカルテ側で行うこと**

## 申し送り

- **`.menu-fold` に `overflow: hidden` を戻さないこと。** 貼り付けが効かなくなる
- 貼り付ける行の地は、**不透明のまま**にすること
