# ISSUE-066: 予約の時間が重なっても、何も出ない

## 概要
- **発生日**: 2026-08-11
- **分類**: MAJOR（取り違えの防止）
- **状態**: **対応済み（案A＋案B）／案C は未実施**
- **担当**: Claude Code

## 症状 / 要望

> 予約時間が重複しないようにしていますか？

**していませんでした。** 調べた結果は次のとおりです。

- 重なりを見る処理は**どこにもありません**（`grep` で0件）
- **同じ日・同じ時間に何件でも入り、警告も出ません**
- 時間は**1時間きざみの選択**で、**所要時間（何分の施術か）を持っていません**

つまり「10時に2人」は止まりませんし、そもそも「10時のアロマ90分」と
「11時のカウンセリング」が重なるかは、**いまのデータでは判断できません**。

気づく手立ては**トップの📅の名前の札だけ**で、これは**日単位**です。
**時間の重なりは、どこにも出ていませんでした。**

## なぜ「禁止」にしなかったか

サロンご自身が ISSUE-063 で挙げられていた懸念（ダブルブッキング）への対応ですが、
**機械的に止める形にはしていません。**

**わざと重ねることがあるためです。** ご家族の同席、見学、
時間をずらして同じ枠に入れる、など。止めてしまうと、そのたびに使えなくなります。

**目的は「防ぐ」ではなく「気づける」**に置きました。

## 直したこと

### 案B：書く前に、その日の予定を見せる

予約画面の上に、その日すでに入っているものを時間順で出します。

```
この日はすでに 1 件あります
10:00  山田 花子  先に入っている施術
```

**書く前に見えていれば、そもそも重ねません。** 案Aより先に効きます。

時間を選び直すと、**同じ時間の行が色付きで目立ちます**。
時間が未定のものは、**重なりの判定に入れません**（判定しようがないため）。控えめに出します。

### 案A：保存のとき、いったん確かめる

```
⏰ 同じ時間に予約があります
8月12日（水） 10:00 には、すでに山田 花子（先に入っている施術）が
入っています。このまま追加しますか？
　　　　　　　　　　　　　　［このまま追加する］
```

**止めません。** 押せば通ります。

### 両方の画面に入れた

予約を書く画面は2つあります（トップ📅の `#booking-modal`、カルテ側の `#record-modal`）。
**両方に入れました。**

片方だけ直して取りこぼす形は、**ISSUE-060・ISSUE-065 と続いています。**
検証にも「カルテ側にも入っているか」の節を置きました。

判定は `findDayBookings()` / `findTimeClashes()` の2つに寄せ、
**同じ規則を2か所に書かない**ようにしています。

## やっていないこと（案C）

**所要時間を持たせて、実際の時間の重なりを判定する**のは入れていません。

- **施術内容ごとの分数を、サロンに決めていただく必要があります。** そこが決まらないと正確に作れません
- 既存の記録にも影響します
- いまの1時間きざみのままなら、**A＋Bで実用上は足りる**と考えます

A・Bを使ってみて、それでも足りなければ着手します。

## 検証結果

`management/09_Verification/verify-clash.js`（スマホ幅390px）

```
=== 1. 書く前に、その日の予定が見えるか
   一覧: "この日はすでに 1 件あります 10:00 山田 花子 先に入っている施術"   ✅
=== 2. 同じ時間を選ぶと、その行が目立つか                                   ✅
=== 3. 別の時間なら、印は付かないか                                         ✅
=== 4. 重ならない時間なら、確かめずにそのまま保存されるか                   ✅ 14 → 15
=== 5. 同じ時間だと、確かめが出るか
   文面: "8月12日（水） 10:00 には、すでに山田 花子（先に入っている施術）
          が入っています。このまま追加しますか？"                           ✅
=== 6. 「このまま追加する」で通るか（止めてしまわないこと）                 ✅ 15 → 16
=== 7. カルテ側の記録画面にも入っているか（片方だけにしない）               ✅ 17 → 18
  ぜんぶ通りました
```

**6が肝心です。** 止まってしまうと、いまより使いにくくなります。
「出るか」だけでなく「**出たうえで通れるか**」まで見ています。

**4も入れています。** いつも確かめが出る実装でも、5・6だけなら通ってしまうためです。

### 直しの途中で1つ整えた

確かめの文が「**10:00 には、すでに 10:00 山田 花子…**」と時刻を二重に出していました。
一行を作る側から時刻を外しました。

## 申し送り

- **時間が未定の予約は、重なりの判定に入りません。** 判定しようがないためです。
  一覧には「時間未定」として出ます
- **所要時間は持っていません**（案C）。「10時90分」と「11時」の重なりは見つけられません
- 判定は **日付＋時間の完全一致**です。1時間きざみの選択なので、実用上はこれで揃います
