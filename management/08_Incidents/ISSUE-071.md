# ISSUE-071: 右下の💬を、使わない間は出さないでおけるようにする

## 概要
- **発生日**: 2026-08-13
- **分類**: 要望（サロンからのご要望）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> 右下のフローティングチャットは今は使わないので一次的に停止して UI からも消してください。
> いつでも再開できるようにしてください。

「一次的に」「いつでも再開できるように」が肝心なところです。
**消すのではなく、止める**。戻す場所を用意しておく、ということです。

## 直したこと

### ① 「⚙️ 設定 →🤖 AI の設定」に切り替えを置いた

```
💬 操作ガイドのチャット
  画面の右下に出る💬のボタンです。使わない間は「出さない」にしておけます。
  消えるのは表示だけで、やりとりの記録は残ります。いつでも戻せます。

  [ 出す ]  [ 出さない ]
```

**既定は「出さない」**にしました。ご要望が「いまは使わない」なので、
サロンのどの端末でも、**何もしなくても消えている**状態から始まります。

### ② 隠すのではなく、組み立てない

止めている間は、チャットの部品を**そもそも作りません**。

隠すだけの直しにすると、見えていないのに裏では
**繋ぎ先を調べに行ったり、キーを読んだり**が続きます。
「止めた」と言えなくなるので、そうしていません。

### ③ 戻すときは、その場で出る

「出す」に戻したら、**読み込み直さずにその場で**出てきます。
戻したのに何も起きないと、効いたのかどうか分かりません。

### ④ 末尾の余白を詰めた

💬 のボタンぶんとして `main` の下に 100px 空けてありました
（星詠み末尾の「次へ」がボタンに隠れるのを避けるため）。
ボタンが無い間は要らないので 24px にしています。

## 検証結果

`management/09_Verification/verify-chat-toggle.js`（新規）

```
=== 1. 何もしていない端末では、💬 が出ないか
  💬 のボタンが無い                       ✅
  チャットの画面も作られていない           ✅
=== 2. 止めている間、AIへ繋ぎに行っていないか  ✅ 0件
=== 3. 末尾の余白が、要らないぶん詰まっているか ✅ 24px
=== 4. 設定に、戻す場所があるか              ✅
=== 5. 「出す」に戻すと、その場で戻るか      ✅（押すとチャットが開くところまで）
=== 6. 読み込み直しても、戻した状態が残るか  ✅
=== 7. もう一度止められるか                  ✅
=== 8. 途中でエラーが出ていないか            ✅ 0件
  ぜんぶ通りました
```

**「消えたか」だけを見ると、消しっぱなしの実装でも通ります。**
ご要望は「いつでも再開できるように」なので、**戻せるところまで**を見ています。

戻りがないことも確認済みです。
`verify-csp` / `verify-manual` / `verify-accordion` / `verify-booking` /
`verify-clash` / `verify-cautions` / `verify-sticky-tabs` / `verify-demos` — **すべて通過**。

### 検証をひとつ、狭めた

はじめ「AIへ行っていないか」を `googleapis.com` を含む形で見ていて、
**画面の書体（fonts.googleapis.com）を拾って**赤くなりました。

繋ぎ先を調べる `/api/ai-status` も外しています。
**設定画面の札にアプリ自身が使う**ので、チャットのせいかを切り分けられないためです。
見ているのは**生成を頼む先**（`/api/chat`・`api.anthropic.com`・
`generativelanguage.googleapis.com`）だけ、と割り切っています。

## 申し送り

- **チャットを使う検証は、先に「出す」にしてから開くこと。**
  既定が「出さない」になったので、`#fc-fab` を待つ検証は永遠に見つかりません。
  `verify-csp` / `verify-manual` / `verify-local-sync` は
  `addInitScript` で `therapist_chat_enabled = 'on'` を入れてあります
- **やりとりの記録・登録したキーは、何も消していません**。戻せば元どおりです
- 設定は端末ごと（`localStorage`）です。**別の端末では、別に設定**します
  （既定が「出さない」なので、放っておけば出てきません）
