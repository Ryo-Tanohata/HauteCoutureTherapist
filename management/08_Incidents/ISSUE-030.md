# ISSUE-030: カルテ側の初診を6つの枠に分け、枠ごとに書き換えられるようにする

## 概要
- **発生日**: 2026-08-06
- **分類**: MINOR (v1.21.0)
- **担当**: Claude Code

## 症状 / 要望

サロンから、初診の項目について改めて指示があった。

> 中身は個別入力するので枠を付けて
> ❤️ Personal ／ ❤️ Reason＆Gole ／ ❤️ 家族構成 ／ ❤️ 病歴 ／ ❤️ 薬 ／ ❤️ memo

続けて「ハートは赤い艶のある❤にしてほしい」との指示。

## 根本原因

ISSUE-028 で6つの枠を作ったのは**顧客登録の画面だけ**だった。カルテ側（情報タブ）は6項目を**ひとつの枠にまとめ、書いてある項目だけを出す**作りにしていた。

そのため、

1. **未記入の項目は見出しごと消える。** 何を訊く欄なのかが分からない
2. **登録済みの顧客に、あとから初診を入れる場所が無い。** カルテを押すと `initialConsultation`（memo）だけの編集になり、Personal や病歴には手が入らなかった

「個別入力する」という指示に対して、読む側が個別になっていなかった。

さらに、記号は `♥︎`（U+2665 + 異体字セレクタ）を使っており、**線画の白抜きハート**として描かれていた。

## 解決策

### 1. カルテ側も6つの枠に分ける（`buildIntakeBoxesHtml`）
登録の画面と同じ6項目を、読む形の枠として並べる。**未記入でも枠は消さない。**

### 2. 枠ごとに、その場で書き換えられるようにする
`startInlineEdit` が `intake.personal` のような書き方を解せるようにし、**他の枠を消さないよう、いまの中身に重ねて書く**ようにした。

```js
const intakeKey = field.startsWith('intake.') ? field.slice('intake.'.length) : null;
// …
updateData.intake = { ...(customer.intake || {}), [intakeKey]: newValue };
```

### 3. ハートを赤い艶のあるものに
`♥︎`（線画）→ `❤️`（U+2764 + U+FE0F）に置き換え。画面とコードで計12か所。

## ついでに直したこと（既存の不具合）

**保存したあと、次の項目に手が入らなくなっていた。**

`startInlineEdit` の保存処理が `closeEdit()` を呼ばずに画面を描き直していたため、`currentActiveEditor` に印が残ったままだった。画面上は編集欄が消えているのに、次の項目を押すと「現在編集中の項目があります」と訊かれ、いいえと答えると何も起きない。

初診に限らず、**電話番号・生年月日・メモなど、カルテ内のすべての項目に前からあった不具合**。保存時に `closeEdit()` を呼ぶよう直した。

## 変更ファイル
- `product/js/app/ui.js`（`buildIntakeBoxesHtml` を追加、`buildIntakeSummary` を削除、`startInlineEdit` の入れ子対応と保存後の後始末）
- `product/index.html`（ラベルのハート、`Reason & Gole` の綴り）
- `product/css/index.css`（`.intake-view` 一式）

## 申し送り: 綴りについて

`Reason & Gole` は、**サロンの指示どおりの綴り**にした。当初こちらで `Goal` に直していたが、2度とも `Gole` と書かれていたため、意図した表記と受け取っている。`Goal` に改める場合は指示があれば直す。
