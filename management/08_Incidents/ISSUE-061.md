## 実質的な影響

### ① 守りの「作り」が読める状態だった

`management/` には、置き場の守り方がそのまま書いてあります。

- 鍵づくりは **PBKDF2-SHA256 / 21万回**
- **ソルトは固定**（`HauteCoutureTherapist|salon-store|v1`。`salon-store.js` にそのまま書いてある）
- 合言葉から2つの値を作り、**片方だけをサーバーへ送る**
- **回数制限が無い**（ISSUE-043 の申し送り）

**これは「作りが知られても破られない」のが正しい姿**です（秘密にすべきは合言葉であって、
仕組みではない）。実際、この設計は仕組みが知られても中身は読めません。

ただし、**ソルトが固定で回数制限が無い**以上、**守っているのは合言葉の強さだけ**です。
そこが唯一の壁だということが、はっきりした形になります。

### ② 置き場の場所は分からない

**リポジトリに本番のURLは書かれていません**（`〇〇.pages.dev` と伏せてある）。
公開されていたものを読んだだけでは、**どこを叩けばよいかが分かりません。**

これは幸運というより、`SALON_ORIGIN` を環境変数にして書かない形にしてあったためです。

### ③ 取り消せないもの

**公開中に誰かが複製（fork / clone）していた場合、非公開にしても消せません。**
GitHub の Insights → Forks で、複製された形跡がないかは確認できます。

## いま必要な対応

**緊急の対応は要りません。** 鍵も合言葉もカルテも出ていないためです。

そのうえで、やっておくと良いものを重い順に。

| | 内容 | 理由 |
|---|---|---|
| 1 | **GitHub の Insights → Forks を見る** | 複製されていないかの確認。5秒で済む |
| 2 | **GitLab 側も Private か確認** | 同じことが起きていないか。Settings → General → Visibility |
| 3 | **合言葉が推測されにくいか見直す** | 上記①のとおり、**守っているのは合言葉の強さだけ**。 変える場合は**いま置いてあるものが読めなくなる**ので、書き出し→変更→入れ直しの手順が要る |
| 4 | （任意）`loutarma@gmail.com` を README から外す | 実害は小さい。すでに公開されている連絡先なら不要 |

**鍵づくり（21万回・固定ソルト）は、サロンの指示により当面触りません。**
これは ISSUE-043 の申し送りのままです。

## どうやって見つかったか

サロンからの指摘です。こちらは **GitHub を「使わない」前提**で作業しており、
**公開状態かどうかを確認していませんでした。**

この日、サロンから「GitHub のバンが解除されたので合わせたい」と言われて
同期したところ、公開だったことが分かりました。

**確認しようとして、確認できなかった経緯も残しておきます。** こちらから
GitHub の公開設定を見ようとしましたが、検索APIが `User flagged as spammy` で
弾かれ、確認できませんでした。**画面で見ていただくようお願いしたのは正解でした。**

### 教訓

**送り先の公開設定は、送る前に確かめる。** 「使わない予定の置き場」は、
そのぶん誰も見ていないので、こういう状態が長く残ります。

## 追記：配信元の取り違え（2026-08-11）

GitHub を同期したあと、サロンから
「GitHub でも CD が動いているという認識でした」と問いがありました。

こちらは「Cloudflare は GitLab を見ている」と答えましたが、
**この対応関係は、プロジェクトの記録のどこにも書かれていませんでした。**
以前のやりとりの記憶で答えており、確認したものではありませんでした。

**もし GitHub が配信元だったら、この日 GitHub の `main` を 148 コミット進めた時点で、
断りなく本番を差し替えていたことになります。**「配信はしていません」と伝えたあとに、です。

サロンに Cloudflare の Deployments 画面を見ていただき、確定しました。

```
Workers & Pages → hautecouturetherapist → 右上: 🦊 loutarma/HauteCoutureTherapist
```

**GitLab でした。** GitHub への push は Cloudflare に何の影響も与えていません。
結果として本番は差し替わっていませんが、**確認せずに答えていた**ことは変わりません。

### 教訓

- **Pages プロジェクト1つに繋がるリポジトリは1つだけ。** 両方を配信元にはできない
- **配信元はコードのどこにも書かれておらず、Cloudflare の画面にしか無い。**
  だから記憶で答えられてしまう。README に書き足した
- **記録に無いことを、記録があるかのように答えない。** 今回は結果的に合っていたが、
  外れていれば営業中のアプリを黙って差し替えていた

## 申し送り

- **公開中の複製は取り消せません。** Forks の確認だけはしておくこと
- **守っているのは合言葉の強さだけ**という状態は、公開の有無にかかわらず変わりません。
  非公開にしたから安全になった、という話ではありません
- **GitLab 側の公開設定は未確認**です。あわせてご確認ください
