## 直したもの

### ① 取り込んだ色の値から、HTML を書き込めた（実際に成立を確認）

**いちばん重いもの。**

`getSoulColorCssValue()` は、`#`・`rgb`・`linear-gradient` で始まる値を
**そのまま返して**いました。返った値は `style="..."` の中へ直に入ります。

```js
const style = `background-color: ${cssVal};`;
return `<span class="soul-dot" style="${style}"></span>`;
```

色に `#ff0000"onmouseover="window.__XSS=1"` を入れると、
**その場で属性が閉じて、好きな属性を足せます。**

**実際にやってみました。** 書き出しファイルの形をした JSON を作り、
📥 読み込みから取り込んだところ、DOM はこうなりました。

```html
<span class="soul-dot" style="background-color: #ff0000" onmouseover="window.__XSS=1" ;""></span>
```

- **本番（CSP あり）では実行されません。** `script-src` に `'unsafe-inline'` が
  無いので、ブラウザが `Refused to execute inline event handler` で止めます
- **CSP の無いところ（`file://` で開いた見本など）では実行されました**

つまり**守っていたのはヘッダー1枚だけ**でした。

取り込みの側（`mergeSnapshot`）は、届いた顧客をそのまま `push` します。
項目ごとの検証はありません。同期で届く中身も同じ道を通ります。

**直したこと**

- `getSoulColorCssValue()` に**形の検証**を入れた。色として意味のある字だけ通す。
  当てはまらないものは、無難な灰色のグラデーションに落とす
- 定義にも当てはまらない値を**そのまま返すのをやめた**（以前は最後に `return color`）
- `style="${}"` の3か所も逃がすようにした（検証済みの値だが、二重に）
- `classList.add('soul-card-' + 色)` を、字と数字だけに削ってから足すようにした。
  **以前は空白を含む値で例外が出て、その顧客のカードが丸ごと描かれなくなっていた**
  （空白を入れると偶然そこで止まる、というだけの守りだった）

### ② 生成AIの文が、そのまま HTML として出ていた

星詠みの本文を `marked.parse()` に直に渡していました。
**marked v12 に sanitize はありません**（v5 で外されたきり）。
文の中に `<img src=x onerror=…>` があれば、そのまま HTML になります。

山括弧だけ先に潰してから渡すようにしました。見出しと箇条書きは、これまでどおり出ます。

（`renderMarkdown()` のほうは、もとから逃がしてから強調だけ戻す作りで、問題ありません）

`server/bridge.js` は **`0.0.0.0` で待ち受け**、**認証は無く**、
`express.static(process.cwd())` で**プロジェクトの中を丸ごと配って**いました。

## 申し送り（直していない・判断が要る）

### ⓐ 合言葉から作った値を、そのまま置き場の鍵にしている

`SALON_KEY` は、暗号化の鍵と**同じ PBKDF2 の出力の後半**です。

「後半から前半は割り出せない」——これは正しいのですが、
**後半を握った人は、合言葉そのものを総当たりで探せます。**
塩は固定で公開、繰り返しは21万回。合言葉が短かったり、よくある言葉だと届きます。
合言葉が割れれば前半＝暗号化の鍵も作れるので、**置き場の中身は読めます**。

`SALON_KEY` を見られる立場（Cloudflare の管理画面に入れる人、
その画面の記録が漏れた場合）に効く話です。
コードのコメントにある「**この窓口を握っても中身は読めない**」は、言い過ぎです。

**直すなら**: 置き場の合言葉を、暗号化とは**関係のない別の乱数**にする。
そうすれば、片方が漏れても、もう片方には効きません。
（いま入っているものを移し替える手順が要るので、サロンとの相談が必要です）

### ⓑ 置き場の合言葉を、中身を失わずに変えられない

合言葉を変えると、暗号化の鍵も一緒に変わります。
**いま置いてあるものは開けなくなります。**
つまり「合言葉が漏れたかもしれないので変えたい」ができません。
ⓐ を直せば、ここも一緒に解けます。

### ⓒ 置き場の窓口に、回数の制限が無い

`/api/sync` は何度でも叩けます。合言葉は256ビットなので総当たりは届きませんが、
**大きなものを何度も置かれると、R2 の容量と通信量は増やせます**。
`MAX_BODY` の確認も、**全部読み込んでから**行っています。

### ⓓ 取り込みと同期の中身を、項目ごとに検証していない

①は色でしたが、**同じ道で他の項目も素通りします**。
いまは画面へ出すところで逃がしているので実害は止まりますが、
**入口で形を確かめるほうが確かです**（日付・金額・区分の key・写真の id など）。
