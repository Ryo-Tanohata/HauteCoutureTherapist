# ISSUE-051: いまどのAIに繋がっているのかが、画面から分からない

## 概要
- **発生日**: 2026-08-07
- **分類**: MINOR（v1.33.0）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> ローカルではclaude agent sdkが使えて、本番環境cloudflareでは使えないという認識です。
> それを明確にしたいので現在使っているAIを確認できる場所が欲しいのですが、
> 設定ページやフローティングチャットのヘッダー部分に現在使っているAIを表示するようにしたいです。

**同じアプリなのに、開き方で繋ぎ先が変わります。**

| 開き方 | 繋ぎ先 |
|---|---|
| サロンのPCで立ち上げて開く | PCのサーバー経由。**Claude のアカウント**（キー不要） |
| いつものURL・スマホ | ブラウザから直接。**登録したAPIキー** |

**見た目では区別が付きません。**
「キーを入れたのに使われない」「キーが無いのに動く」の元になっていました。

## 作業中に見つけた、こちらの手落ち

**同じものを二重に作りかけました。**

設定画面には**すでに `#ai-route-status` という表示がありました**（`/api/ai-status` を
叩いて、どの提供元を先に使うかまで出す、こちらのほうが詳しいもの）。
それに気づかず、新しいパネルを作り始めていました。

**探さずに作り始めたのが原因**です。取り下げて、作りかけを捨てました。

そのうえで、なぜサロンが気づかなかったのかを見ると、
**「🤖 AI の設定」がたたまれた見出しの中**にあり、**開かないと見えない**ためでした。

## 解決策: たたんだままでも見える「札」にする

詳しい表示（既存）はそのまま残し、**見出しの行に短い札**を出すようにしました。

```
🤖 AI の設定   ● このPCの Claude
```

**開かなくても、色と一言で分かります。**

| 色 | 意味 |
|---|---|
| 🟢 緑 | **Claude のアカウント**で動いている（キー不要） |
| 🔵 水色 | 登録したAPIキーで動いている |
| 🔴 赤 | まだ繋がっていない |

同じ札を、**操作ガイドのヘッダー**にも出しています。

### 作りかた

`product/js/app/ai-route.js` を新しく置き、**繋ぎ先を調べる仕事をここ1か所**にまとめました。

- `/api/ai-status` に短く（2.5秒で打ち切り）訊く。返事があればPCのサーバーが居る
- 居なければ、登録されたキーの種類から判断する
- 開いている間は結果を取っておく。キーを足し引きしたら調べ直す

**チャットの部品には、繋ぎ先を知らせていません。** `setRoute()` という
差し込み口を用意し、**何を出すかはアプリ側が決める**形にしました。
この部品は他でも使い回せるので、アプリ固有の事情を中に埋めないためです。

## 検証結果

`management/09_Verification/verify-ai-route.js`。
PCのサーバーが居る状態を作って（`/api/ai-status` の返事を差し替えて）確かめています。

| 調べたこと | 結果 |
|---|---|
| サーバーが居て Claude のとき | **「このPCの Claude」／緑** |
| サーバーが居ない＋キーがあるとき | **「登録したAPIキー（Anthropic（Claude））」／水色** |
| サーバーも居ない・キーも無いとき | **「まだ繋がっていません」／赤** |
| チャットのヘッダーにも同じものが出るか | **出る（色も一致）** |
| **たたんだままでも見えるか** | **見えている**（150×21px） |
| 待たされないか | **278ms** |
| スマホ幅（390px） | **はみ出し0px** |

既存のもの（`verify-csp.js` / `verify-keys-unified.js`）も通っています。

## 申し送り

- 札は**開いた時点の状態**です。あとからPCのサーバーを立ち上げても、
  画面を開き直すまで変わりません
- 繋ぎ先を調べる仕事は `ai-route.js` の1か所です。
  **判定を変えるときは、そこだけ直せば両方に効きます**
