# ISSUE-048: 説明書が丁寧でも「どこのことか」が分からない

## 概要
- **発生日**: 2026-08-07
- **分類**: MINOR（v1.31.0）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> 説明はすごく丁寧なんですがどこのことを言ってるのか 初めての人は難しいです
> それぞれの説明の動画を作ってもらえますか
>
> デモを作る時と同じ要領だと思いますが

ISSUE-047 で説明書を作りましたが、**言葉は分かっても、画面のどこを指しているかが分からない**
という指摘でした。「⚙️ 設定を開く」と書いてあっても、初めての人には
**設定がどこにあるかが分からない**。

## 解決策: 実物を動かして、そのまま録る

絵で描いた作り物ではなく、**実物のアプリを本当に動かして録画**します。
サロンからの「デモを作る時と同じ要領」という見立てのとおりです。

```
node management/09_Verification/serve-with-headers.js   （実物を配る）
node scripts/build-manual-videos.js                     （録る）
```

作り物にしなかった理由は、**アプリを変えたときに絵だけ古くなるのを避けるため**です。
録り直せば、必ず今の画面になります。

### 動画に入れたもの

| | 中身 |
|---|---|
| **丸い印** | 次にどこを押すかを、動く丸で示す |
| **囲い** | 押す前に、その場所を四角で囲む |
| **字幕** | 何をしているかを、画面の下に焼き込む |
| **打つ様子** | 文字は1文字ずつ入る（貼り付けではなく、人が打つ速さ） |

**音は入れていません。** 施術中でも見られるようにするためです。

## 説明書との結びつけ方

動画の一覧は `docs/videos/videos.json` に置き、
**「2-1.」のような見出しの頭の番号**で結びつけます。

**説明書そのもの（`manual.md`）には、動画のことを書いていません。**
操作ガイド（AI）に渡すのは字だけでよく、ファイルの置き場所まで読ませても
答えの役に立たないためです。原本は字のまま、動画は添え物、という分け方です。

## 作業中に見つかった落とし穴

### 1. 画面の外にあるものは、押せない

カレンダーの下のほうのマスや、入力欄が画面の外にあると、
`Element is outside of the viewport` で止まります。
**丸を動かしている間に画面が描き直され、位置がずれる**のが原因でした。

押す直前にもう一度その場所へ寄せ、それでも届かなければ**要素そのものを押す**
形にしました（見た目は変わりません）。

### 2. 記録は「編集を有効にする」を押すまで、手が入らない

2-6（施術のあとの記録）が途中で止まっていました。
記録を開いた直後は**読むだけ**の状態で、
`#btn-toggle-edit-record` を押してはじめて書けるようになります。

**これは説明書にも書いていなかった手順**だったので、台本と説明書の両方に足しました。

### 3. 設定の中は、たたまれている

「一覧に出す呼び名」（1-4）の台本が止まりました。調べたら、設定の中は
`<details>` でたたまれた見出しに分かれていて、
**「📝 記録の設定」を押して開かないと、中が見えません。**

説明書には「⚙️ 設定 の『一覧に出す呼び名』で選べます」としか書いていませんでした。
**開く手順が抜けていた**ので、こちらも両方に足しました。

**動画を作ったことで、説明の抜けが2つ見つかった**形です。
文章だけ書いていたら、どちらも気付かないままでした。

## 検証結果

`management/09_Verification/verify-videos.js`。

| 調べたこと | 結果 |
|---|---|
| 動画が添えられているか | **15本** |
| 守りに弾かれていないか | **0件** |
| **見出しと中身が食い違っていないか** | **15本すべて一致** |
| 実際に再生できるか | **進む。1024x760・28秒** |
| 開いた瞬間に12MB取りに行かないか | **先読み0本**（`preload="none"`） |
| スマホ幅（390px） | **はみ出し0px。動画も収まる** |

**見出しと中身の食い違いを見る**のは、ここが一番まずい間違い方だからです。
違う動画が付いていても、画面はふつうに出てしまいます。

## 申し送り

- **アプリの見た目を変えたら、録り直してください。** 番号を指定すれば1本だけ録れます
  （`node scripts/build-manual-videos.js 2-1`）
- 台本は `scripts/build-manual-videos.js` の `SCENES` にあります。
  場面を足したいときは、そこに1つ書き足すだけです
- **第2章の12場面は、すべて録りました。** ほかに要るものがあれば足します
- 合計23MB。開いた瞬間には取りに行かない形にしてありますが、
  これ以上増やすときは総量に気をつけてください
