# ISSUE-037: カレンダーの押し分けを整理し、ホーム画面のアイコンをサロンの絵にする

## 概要
- **発生日**: 2026-08-07
- **分類**: MINOR (v1.24.0)
- **担当**: Claude Code

## 症状 / 要望

1. **日付のマスを押したら、その日に登録してある人を全員出してほしい**
2. **下に出た一覧を押したら、その人の予約内容が出てほしい**
3. そのとき、**未来の日は「予約」、過去の日は「カルテ」**が出るようにしたい
4. **予約とカルテは同じものに書く作りになっているか**を確認したい
5. スマホでホーム画面に置くとき、**アプリの綺麗な絵がアイコンになるようにしたい**

## 4. の回答: 同じものです

**予約とカルテは、同じ1件の記録です。** 別々の入れ物は持っていません。

`addRecord()` が作る記録には、日付・時間・施術内容・金額に加えて、訴え・処方・メモ・色・写真が入ります。**「予約かどうか」を表す印は、どこにもありません。**

```js
const newRecord = {
    id, date, type, amount, time,
    clientComplaint, prescription, therapistNote,
    colors, advanceSet, categories, photos, kartes,
    updatedAtISO
};
```

違うのは**日付だけ**です。

- `date` が今日より後 → まだ来ていない → **予約**
- `date` が今日以前 → もう済んだ → **カルテ**

同じ記録が、日が過ぎれば予約からカルテに変わります。**予約のときに書いた時間や施術内容は、そのままカルテの一部として残ります。** 施術のあとで訴え・処方・メモを書き足せば、カルテとして仕上がります。二重に登録する必要はありません。

## 根本原因（1〜3について）

ISSUE-029 で「札を押すとその人のぶんだけ出す」ようにしたが、実際に使うと**マスの空いているところが狭く、全員を見るのが難しい**（スマホの1マスは41px、そこに札が3枚並ぶ）。

また、一覧を押すと**日付にかかわらずカルテが開いていた**。まだ来ていない人のカルテを開いても、書くことが何も無い。

## 解決策

### 押し分けを1段ずつに整理
- **マスを押す（札の上でも可）** → その日の**全員**が下に出る
- **一覧の1件を押す** → その人の中身が出る
  - **未来の日** → 予約の内容（見出しも「予約の内容」に変えた）
  - **過去の日** → カルテ（📋タブが開き、その日の記録が光る）

札ごとの絞り込みと「← この日の全員を見る」は、要らなくなったので外した。

### ホーム画面のアイコン
`manifest.webmanifest` を用意し、サロンの絵から作ったアイコンを載せた。これが無いと、端末は URL の頭文字（「P」）で四角い印を作ってしまう。

- 元絵は `salon-art-banner.webp`（1000×419）。**いちばん解像度の高いもの**から正方形に切り出した（`salon-art-mark.webp` は192pxしかない）
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png`（180px）
- `maskable` も同じ絵。絵画なので、端末が丸や角丸に切っても成立する
- `theme-color` と `apple-mobile-web-app-*` も併せて指定

## 変更ファイル
- `product/js/app/ui.js`（押し分け、予約の見出し）
- `product/css/index.css`（`.btn-show-all-day` を削除）
- `product/index.html`（アイコンと manifest の指定）
- `product/manifest.webmanifest`（新規）
- `product/images/icon-192.png` / `icon-512.png` / `apple-touch-icon.png`（新規）
- `README.md`（存在しない `product/_routes.json` の記述を修正）

## 申し送り

**アイコンの反映は、いったんホーム画面から消して置き直す必要がある。** 端末は最初に置いたときのアイコンを持ち続けるため、更新しても自動では変わらない。
