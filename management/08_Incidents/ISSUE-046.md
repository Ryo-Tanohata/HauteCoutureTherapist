# ISSUE-046: 長押しの説明が、指を離した瞬間に消える

## 概要
- **発生日**: 2026-08-07
- **分類**: MINOR（v1.29.0）
- **状態**: **配布済み**（2026-08-07 / `0bc1a1e`）
- **担当**: Claude Code

## 症状 / 要望

> アイコンを長押しすると説明が出てきますが指を外しても少しの間 説明が出ているようにしたいです

ISSUE-028 で「押している間はずっと出す」ようにしましたが、実際に使うと
**離した瞬間に消える**ので、読み終わる前に消えていました。

押している指が説明にかぶることもあり、**離してから読みたい**という形でした。

## 根本原因

指を離したときの後始末が、**説明を消すところまで一気にやっていました。**

```js
const endPress = () => {
    clearTimeout(longPressTimer);
    cleanupTooltip();      // ← ここで即座に消えていた
    restoreTitle();
};
```

## 解決策: 離してから、ひと呼吸だけ残す

離しても消さず、**1.8秒そのまま置いてから、0.35秒かけて薄くして**消します。

| | 時間 |
|---|---|
| 押してから出るまで | 0.5秒（前のまま） |
| **離してから、そのまま残る** | **1.8秒** |
| 薄くなって消えるまで | 0.35秒 |

読み終わるだけの間はありつつ、次の操作の邪魔にならない長さにしました。
**次を押せば、その場で入れ替わります**（待たされません）。

## 作業中に気付いた、2つの落とし穴

### 1. 指を離すと `click` が続けて来る

`click` の側でも説明を消していたため、**そのままでは見送りが打ち消され、
離した瞬間に消えたままでした。** 長押しから続いた `click` のときは消さず、
別のところを押した `click` のときだけ消すようにしました。

```js
if (didShow) {
    didShow = false;
    e.preventDefault();
    e.stopPropagation();
    return;        // 読んでいる途中なので、まだ消さない
}
cleanupTooltip();
```

### 2. `touchmove` は何度も来る

指を少し動かすだけで何十回も来ます。そのたびに見送りを始めると、
**消えるまでの時間が伸び続けて、いつまでも残る**ことになります。
既に見送りに入っていたら何もしない、という形にしました。

どちらも、**動かして初めて出た**ものです。

## 検証結果

`management/09_Verification/verify-tooltip-linger.js`。
実物を390px・タッチありで開き、実際の指と同じ順番（`touchstart` → `touchend` → `click`）で
イベントを起こしています。

| 調べたこと | 結果 |
|---|---|
| 押している間に出るか | **出る** |
| 離した直後も残っているか | **残る** |
| 1.3秒後もまだ読めるか | **読める** |
| 2.7秒後には消えているか | **消えている** |
| 残っている間に次を押したら、すぐ入れ替わるか | **入れ替わる** |
| `touchmove` を連打しても、消えるまでが伸びないか | **伸びない** |

## 申し送り

- 消えるまでの時間は `ui.js` の `LINGER_MS` / `FADE_MS` と、
  `index.css` の `tooltipFadeOut` で**2か所に分かれています。** 片方だけ変えると、
  消える前に消えたり、消えたあとも残ったりします。両方のコメントに書き添えました
- 長すぎる／短いと感じたら、`LINGER_MS` の数字だけで直せます
