# ISSUE-077: 👤「情報」を、名前を押して開く形にした（タブ 5→4）

## 概要
- **発生日**: 2026-08-15
- **分類**: 要望（サロンからのご要望）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> ↑この部分も同じだと思うので人影のアイコン部分はなくてokです
> 名前をタップすると個別情報が開ける様にお願いしたいです🤲
> 開いたページに編集アイコンが出て来て、押すと編集できるのがいいと思います
> Soulcolorの自動計算欄は無しで❣️
> 全体ページでは名前とSoulcolor出てるのですが
> 個人ページでも名前の横に常に表示したいです

## 直したこと

### ① 👤 のタブを外した（タブ 5→4）

```
📋 カルテ ／ 🗓️ カレンダー ／ 💴 金額 ／ ✨ 星
```

**中身は消していません。** 氏名・ニックネーム・生年月日・紹介者・Soul Color・
初診・メモは、カルテには無い情報です。**名前を押して開く**形に移しました。

### ② 名前を押すと「この方のこと」が開く

```
Julie ●●●●●  ›     🟢通常顧客
```

押せることが分かるよう「›」を添え、開いている間は水色に倒れます。
他のタブを押せば、いつでもカルテへ戻れます。

### ③ 開いた先は、押すまで読むだけ

これまでは**欄に触れた瞬間に編集が始まって**いました。
施術中に画面を送っていて、うっかり生年月日を書き換える、が起こりえます。

`✏️ 編集する` を押すまで、どの欄も動きません。
**別の方へ移ったときと、他のタブへ移ったときは、必ず読むだけに戻します。**
直せる状態を置き去りにしないためです。

### ④ ソウルカラーの自動計算を、カルテから下ろした

**顧客を登録するときには、これまでどおり出ます。** 色を決める助けなので、
そこは残しました（`buildSoulAutoDetailHtml()` は登録の画面で使い続けています）。

下ろしたのは、カルテ側の「登録と異なります」を出す畳みだけです。

### ⑤ ソウルカラーを、名前の横に常時表示

一覧と同じ部品（`buildSoulColorBadgeHtml`）を使うので、**見た目も揃います。**
開かないと見えないのでは、顔ぶれを思い出す手がかりになりません。

## 作業中に見つけたこと

**タブを外したことで、3か所が黙って壊れていました。**

| 場所 | 何が起きていたか |
|---|---|
| 「その他」の棚卸し → 体質へ飛ぶ道 | `.tab-btn[data-tab="personal-info"]` を押しに行き、**何も起きない** |
| ソウルカラーのデモ | 「情報」タブへ行き、**消した自動計算の畳み**を開こうとする |
| 問診と体質のデモ | 「情報」タブへ行こうとする |

いずれも `if (el)` で囲ってあるので、**エラーも出ず、黙って飛ばされます**。
ISSUE-069 に書いた「デモは壊れない、短くなるだけ」が、そのまま出た形です。

3つとも新しい道（`openPersonalInfo()` / `#detail-name-open`）へ向け直しました。
デモの文面も差し替えています。

```
2. 名前を押すと「この方のこと」が開きます
```
