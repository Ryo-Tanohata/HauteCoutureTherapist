# ISSUE-067: 重なりの知らせが、時間を選ぶ場所から遠くて気づけない

## 概要
- **発生日**: 2026-08-11
- **分類**: MINOR（見せかた）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

ISSUE-066 を配信した直後のご指摘です。

> これだけだと分からないので、時間を決める所に赤い警告が出るようにしたいです

さらに、いったん欄の下に赤い枠を出したところ、

> 時間の中に出るのだと場所も省略できるしわかりやすいです
> 時間の欄の中で時間のすぐ隣とか

## 根本原因

ISSUE-066 では、**画面のいちばん上の一覧で色を変えるだけ**にしていました。

```
この日はすでに 2 件あります
02:00  Julie   ion detox・CBD
12:00  LOU     無料カウンセリング   ← ここが色付きになる
```

ところが**時間を選ぶ欄は、ずっと下の「詳細メモ」の畳みの中**にあります。
選んでいる場所と、知らせている場所が離れていました。

**「出している」と「気づける」は違う。** そこを取り違えていました。

## 直したこと

### 選択肢そのものに書き込む

```
12:00　⚠️ LOU
13:00
14:00　⚠️ 山田 花子 他1名
```

サロンのご指摘のとおり、**これがいちばん良い形**でした。

- **選ぶ前から埋まりが見える。** 開いた瞬間に、空いている時間が分かる
- **場所を取らない。** 欄の外に枠を置く必要がない
- **誰が入っているかも同時に分かる**

元の文字は `data-baseLabel` に控えて付け直しています。
控えておかないと、**開くたびに ⚠️ が積み重なります**（検証に入れてあります）。

### 選んだ時間が埋まっていたら、欄そのものを赤くする

```css
select.has-clash {
    border-color: #ff5252 !important;
}
```

### 畳んだままでも分かるようにする

**時間の欄は「詳細メモ」の畳みの中にあります。** 畳んだままだと、
上の直しはどちらも見えません。そこで、**畳みの外**にある一覧の見出しにも出します。

```
この日はすでに 2 件あります　⚠️ いま選んでいる 12:00 は重なっています
```

### 自分自身は数えない

既存の予約を開いたときに、**自分と重なっている**と出ては意味がありません。
編集中の記録は判定から外します。

## 検証結果

`management/09_Verification/verify-clash.js`（第8〜11節を追加）

```
=== 8. 時間の選択肢に、埋まっていることが出るか
   13:00 の選択肢: "13:00　⚠️ 山田 花子"                      ✅
   17:00 の選択肢: "17:00"                                     ✅（空きには付かない）
=== 9. その時間を選ぶと、欄そのものが赤くなるか
   枠の色: rgb(255, 82, 82)                                    ✅
  畳んだままでも、見出しに重なりが出る                         ✅
=== 10. 空いている時間に戻すと、印が消えるか
  印が二重に付かない: "13:00　⚠️ 山田 花子"                    ✅
=== 10b. カルテ側の記録画面でも同じか                          ✅
=== 11. 既存の予約を開いたとき、自分自身と重なったことにならないか
   自分の時間の選択肢: "19:00"                                 ✅
  ぜんぶ通りました
```

### 検証で3回つまずいた

**① 畳みの中は「見えていない」。** `isVisible()` が false になった。
これは検証の不備ではなく、**実際にサロンが見えない**ということ。
畳みの外にも出す直しにつながった。

**② 色が oklab で返り、赤と判定できなかった。**

```
枠の色: oklab(0.999994 0.0000455678 0.0000200868 / 0.0784314)
```

`.form-control` に `transition: all 0.3s` があり、**色が変わっている途中の値**を
読んでいた。しかも畳まれていると、途中の値のまま止まって見える。
**開いてから、変わり終わるのを待って測る**ようにした。

**③ 11番が、他の予約と重なっていて判定にならなかった。**
それまでの節で何件も置いていたため、「自分以外とも重なっている」状態だった。
**まっさらにしてから1件だけ置く**形に直した。

## 申し送り

- **端末によっては、`option` の文字色を反映しません。** そのため色に頼らず、
  **⚠️ と名前という「文字」**で示しています。文字なら必ず出ます
- 判定は ISSUE-066 と同じ **日付＋時間の完全一致**です。所要時間は持っていません
