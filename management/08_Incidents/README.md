# 見つかったことの一覧

サロンからのご要望だけでなく、**作業の途中で見つかった小さな不具合や気付き**も、ここに残す。
「そのとき直したから、もういい」で流すと、同じことを繰り返すため。

## 書き方の決めごと

- **要望から始まったもの** … 症状 / 根本原因 / 解決策 / 検証結果 を書く
- **作業中に見つかったもの** … それに加えて、**どうやって見つかったか**を書く。同じ見つけ方が次にも効くため
- **直していないもの** … 状態を「未修正」とし、**なぜいま直さないか**を書く
- **こちらの誤りだったもの** … 消さずに、誤診として残す
