# ISSUE-083: 「下ごしらえ」を止めた（消してはいない）

## 概要
- **発生日**: 2026-08-21
- **分類**: 要望（サロンからのご要望）
- **状態**: **対応済み**
- **担当**: Claude Code

## ご要望

> 現在のところ 下ごしらえは不要です 復活するかもしれないのでその時はどうするかを
> 相談したいです 完全に消していいのか コメントアウトしておくのか
> 他に何かあるのか っていうところを相談したいです

3つを並べてご相談し、**「止めるだけ」**を選んでいただきました。

| やり方 | 弱点 |
|---|---|
| **止めるだけ**（採用） | 使っていないコードが残る |
| 消して git から戻す | 戻すときには周りが変わっている。下ごしらえは繋がりが広く、貼り直しでは済まない |
| コメントアウト（**勧めなかった**） | 動かないので、周りが変わっても**壊れたことに気づけない**。検証も素通りする。読む人にも消し忘れか判断できない |

💬チャット（ISSUE-071）で一度通した形と同じです。

## 直したこと

`product/js/app/prep-visibility.js` を足し、⚙️設定の「🤖 AI の設定」に
「🍳 下ごしらえ」の切り替えを置きました。**既定は「使わない」**です。

止まるのは3か所。

- カルテの記入画面の「下ごしらえを作る／訴えを反映して作り直す」（**作る入口はここだけ**）
- 📅の予約カードに出る「✓ 下ごしらえ済み」の印
- ⚙️設定の「AI提案のAPIキー」と繋ぎ先の表示

**隠すだけにしていません。** 使わない設定のときは、ボタンの組み立てもしませんし、
繋ぎ先を調べに行くところ（`/api/ai-status`）も動きません。
隠すだけだと、裏でキーを読み、ネットワークへ出続けます。

**書かれた記録は消えません。** 過去に下ごしらえから入った処方やメモは記録の中に残っており、
使う設定に戻せばまた画面に出ます。

## 途中で分かった、思っていたのと違ったこと

- **AIを使うのは下ごしらえだけ、と一度お伝えしたのは誤りでした。**
  `product/js/app/*.js` しか探しておらず、`product/js/vendor/` を見ていませんでした。
  💬チャットも `generateWithOwnKey` と同じキーを読みます
  （`js/vendor/floating-chat/integrations/entry-aurora.js`）。
  そのため、キーの欄は**下ごしらえと💬のどちらかが「使う」なら出す**形にしました
  （`isAiKeyNeeded()`）。下ごしらえだけを見て畳むと、
  **チャットを使う人がキーを入れられなくなります**

- **「下ごしらえは2か所」も誤りでした。** 予約カードにあるのは作るボタンではなく
  「下ごしらえ済み」の**印**だけです。作る入口はカルテの1か所でした

- **案内（デモ）が、隠したボタンをそのまま説明していました。**
  ボタンは隠しただけで DOM には残るので、`if (adviceBtn)` は素通りします。
  見えないボタンを案内したうえ、押しても何も起きず、結果を待って止まります。
  使う設定のときだけ流れるようにしました（カルテのデモは 23手順 → 16手順）

- **`.visit-prep` を指すデモの手順が、すでに死んでいました。**
  その class は markup に無く、`if (prepBtn)` に守られてずっと素通りしていました。落としました

- **`verify-ai-route.js` は、私の変更の前から止まっていました。**
  💬を既定で出さなくした ISSUE-071 以降、チャットの札を見に行く所で30秒待って落ちていました。
  検証側で「使う」設定にしてから見るように直しました

## 気づいたこと

- **同じブラウザのまま検証を続けると、前の手順で変えた設定が残る。**
  手順5で「使う」に戻したまま手順6を走らせ、使う設定のまま試して
  「通った」ことにしていた。切り替えを試す検証では、**見る前に戻す**こと
- **ネットワークの見張りに `googleapis.com` と書くと、Google Fonts まで拾う。**
  AIの入口（`generativelanguage.googleapis.com`）を指すこと
- **「出ていない」を確かめる検証は、「出る」ほうも試さないと意味がない。**
  0件だから止まっている、は見張りが壊れていても同じ結果になる

## 申し送り

- **戻すときは、⚙️設定 →「🤖 AI の設定」→「🍳 下ごしらえ」を「使う」に。**
  ボタンの組み立ては読み込みのときに決まるので、**画面の読み込み直しが要ります**
- **ISSUE-082 の申し送りは、まだ閉じていません。** 使う設定に戻すと、
  下ごしらえは**画面に無い処方欄**に書き込みます（ISSUE-080 で下ろしたため）。
  戻すときは、処方欄を画面に戻すか、メモへ一本化するかを決めること
