# ISSUE-033: 保存したあと、次の項目に手が入らなくなる

## 概要
- **発生日**: 2026-08-06（ISSUE-030 の検証中に発見）
- **分類**: BUGFIX
- **状態**: **修正済み**（ISSUE-030 と同じ変更に含めて修正）
- **担当**: Claude Code

## 症状

カルテの中の項目をひとつ書き換えて保存すると、**そのあと別の項目を押しても編集できない**。

押すと「現在編集中の項目があります。別の項目を編集しますか？」と訊かれ、いいえと答えると何も起きない。はいと答えれば編集できるが、画面上はどこも編集中に見えないため、**何を訊かれているのか分からない**。

初診に限らず、**電話番号・生年月日・氏名・メモなど、カルテ内のすべての項目**で起きていた。前からあった不具合。

## 根本原因

`startInlineEdit` は、編集を始めるとき `currentActiveEditor` に「いま編集中」の印を置き、閉じるとき `closeEdit()` で消す仕組みになっている。

```js
currentActiveEditor = { close: closeEdit };
```

ところが**保存の処理が `closeEdit()` を呼ばずに `showCustomerDetail()` で画面を描き直していた**。描き直しで編集欄そのものは消えるが、**印だけが残る**。次に別の項目を押すと、冒頭のこの判定に引っかかる。

```js
if (currentActiveEditor) {
    if (!confirm('現在編集中の項目があります。別の項目を編集しますか？')) return;
    closeActiveEditor();
}
```

キャンセル（✕）のほうは `closeEdit()` を呼んでいたため、**保存したときだけ**起きていた。

## 解決策

保存時にも `closeEdit()` を呼んでから描き直すようにした。

```js
updateCustomer(customer.id, updateData);
closeEdit();          // ← これが無かった
showToast('更新しました', 'success');
showCustomerDetail(customer.id);
```

## 見つかった経緯

ISSUE-030（初診の6枠）の検証で、**病歴の枠を書き換えたあと、続けて memo の枠を書き換える**手順を書いたところ、4番目の検証だけが通らなかった。テストの書き方の問題かと疑ったが、手で追っても同じだったため、製品側の不具合と判明した。

**ひとつの項目しか直さない検証だったら、見つかっていなかった。**
