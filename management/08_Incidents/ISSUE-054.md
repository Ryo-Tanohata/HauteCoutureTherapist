# ISSUE-054: ローカルで開いている間、端末をまたぐ同期が丸ごと止まっていた

## 概要
- **発生日**: 2026-08-07
- **分類**: MAJOR（v1.36.0）／**データが他の端末へ届かない**
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状

サロンから送られた画面の**右上が赤くなっていました**。

```
⚠ 送れていません
```

ご質問は別のこと（モデル名の表示）でしたが、**こちらのほうが重い**ので先に調べました。

## 根本原因: 置き場の窓口が、Cloudflare 側にしか無い

置き場とやりとりする窓口は `functions/api/sync.js`（Cloudflare Pages の関数）だけです。
**ローカルの `bridge.js` には、その入口がありませんでした。**

つまり、

| 開き方 | AI | **同期** |
|---|---|---|
| いつものURL | キーが必要 | ✅ 動く |
| **このPCで立ち上げて開く** | ✅ アカウント（キー不要） | ❌ **止まる** |

**Claude のアカウントを使うためにこの開き方をすると、その間に書いたカルテが
他の端末へ届かない。** いちばん困る形です。

しかも書いた本人の画面では、記録はちゃんと残って見えます。
**気づくのは、別の端末で「無い」と分かったときです。**

## どうして気づけなかったか

ローカルでの確認は、**AIが動くかどうかしか見ていませんでした。**
同じ開き方で**同期まで通るか**は、一度も確かめていません。

サロンから送られた画面の隅に写っていた赤い札で気づきました。
**質問された箇所だけを見ていたら、見落としていました。**

## 解決策: ローカルの窓口が、そのまま置き場へ運ぶ

`bridge.js` に `/api/sync` を足し、**中身を触らずに転送**します。

```js
app.all('/api/sync', express.raw({ type: '*/*', limit: '20mb' }), async (req, res) => { ... });
```

- **中身は端末で暗号化済み**なので、ここを通っても読めません
- 合言葉の照合も向こう側でやります。**ここは運ぶだけ**
- 返ってきた状態（401・404 など）も、そのまま返します

### 置き場の場所は、リポジトリに書きませんでした

`SALON_ORIGIN` として渡す形にしています。

```bash
SALON_ORIGIN=https://〇〇.pages.dev npm run dev
```

ISSUE-045 で「**入口を探せる場所に置かない**」と決めたので、それに揃えました。
渡さずに立ち上げた場合は、**何をすればよいかを書いた断り**を返します。

## 検証結果

置き場のふりをするものを立て、`bridge.js` 経由で通しました。

| 調べたこと | 結果 |
|---|---|
| 合言葉つきの ping | **通る**（`{"ok":true}`） |
| 合言葉が違うとき | **401 がそのまま返る** |
| まだ何も無いとき | **404 がそのまま返る** |
| **暗号のかたまりが、1バイトも変わらず往復するか** | **完全に一致**（21バイト） |

そのうえで、実物のアプリで通しました（`verify-local-sync.js`）。

| 調べたこと | 結果 |
|---|---|
| つないだあとの札 | **`☁ 8/7 23:34`／`is-ok`**（赤くない） |
| 書いたあと、送れているか | **送れている**（未送信のまま残らない） |
| AIの札（聞く前） | `アカウント · claude-haiku-4-5` |
| **AIの札（答えた後）** | **`アカウント · claude-haiku-4-5-20251001`** |
| チャットがアカウントで答えているか | **答えている** |

## 申し送り

- **確認は、質問された箇所だけ見ない。** 今回は画面の隅の赤い札が答えでした
- **「AIが動くか」と「データが届くか」は別々に確かめる。** 片方だけ通っても、
  もう片方が止まっていることがあります
- `SALON_ORIGIN` を渡さずに立ち上げると、**同期だけが止まります**（AIは動きます）。
  分かるように断りを出していますが、**渡して立ち上げる癖をつけるほうが確実**です
