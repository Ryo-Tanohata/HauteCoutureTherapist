# ISSUE-038: カレンダーの札を2枚までにし、3人目からは「他N人」にする

## 概要
- **発生日**: 2026-08-07
- **分類**: PATCH (v1.24.1)
- **担当**: Claude Code

## 症状 / 要望

> 3人目から他◯人にして下さい

## 根本原因

1日に並べる札を **3枚まで**としていた（`CALENDAR_NAME_CARDS = 3`）。そのため4人以上の日は

```
 6
 LOU
 Julie×3
 田中
 他1人
```

と**4段になり、その週だけマスが縦に伸びて**、月ぜんたいの見通しが悪くなっていた。

「他1人」のためにもう1段使うのは割に合わない。**3枚目を出すくらいなら、まとめてしまったほうが月として読みやすい。**

## 解決策

`CALENDAR_NAME_CARDS` を **2** にした。3人目からは「他N人」にまとまる。

```
 6
 LOU
 Julie×3
 他2人
```

まとめられた人の名前は、これまでどおり「他N人」を長押しすると出る。マスを押せば、下の一覧に**全員**が出る（ISSUE-037）。

## 変更ファイル
- `product/js/app/ui.js`（`CALENDAR_NAME_CARDS`）

## 検証結果（本物のアプリを 390px で実測）

```
4人いる日   ["LOU","Julie×3","他2人"]        ✅
            「他2人」の吹き出し: 田中 結衣 / 鈴木 一郎
2人いる日   ["佐藤","長谷川"]                 ✅（まとめない）
1人だけの日 ["長谷川"]                        ✅

「他2人」を押す → 一覧に6件（LOU1 + Julie3 + 田中1 + 鈴木1）  ✅
                  まとめられた田中さん・鈴木さんも出る          ✅

4人いる日のマスの高さ 67px（4段のときより1段ぶん低い）
ページエラー 0件
```
