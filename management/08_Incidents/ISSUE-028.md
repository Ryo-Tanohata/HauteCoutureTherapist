# ISSUE-028: カルテのリニューアル（Terre Mer KARTE・初診欄・時間帯・施術内容・記号表記）と、押している間の説明

## 概要
- **発生日**: 2026-08-06
- **分類**: MINOR (v1.19.0)
- **担当**: Claude Code

## 症状 / 要望

サロンから、実際に使ってみたうえでの変更要望が届いた。

1. **タイトル**: 「セラピスト向け〜」を **Terre Mer KARTE** に
2. **Soul Color の名前version**: サロンの姓名判断の計算とは違うので、連動しなくてよい
3. **初診**: 見出しは「初診」ひとつだけ。中身は個別入力するので枠があればよい
   ♥︎ Personal ／ ♥︎ Reason & Goal ／ ♥︎ 家族構成 ／ ♥︎ 病歴 ／ ♥︎ 薬 ／ ♥︎ memo
4. **時間選択**: 0〜24時すべて。靈氣やアニマルコミュニケーションを夜中にやることが多い
5. **施術プラン → 施術内容**: 名称変更のうえ、金額を連動させる
6. **2回目以降のカルテ**: クライアントの訴え→🌸、処方→🧪、メモ→🐬 の記号のみ

続けて、実機（Android）で使ったうえでの指摘が3件届いた。

7. **個人の Soul Color に TC・Adv は不要**
8. **📋タブの名前は「施術内容」ではなく「カルテ」**
9. **アイコンを長押ししている間は、ずっと説明を出してほしい。** また、文字のあるボタンだと長押し中に文字が選ばれてしまうので、ボタン内の文字には反応せず説明だけ出るようにしたい

## 根本原因

- **時間帯**: 営業時間を日中と決め打ちし、`<option>` を静的に書いていた。夜間の施術が想定から抜けていた
- **Soul Color の説明文**: 画面に「上段3色＝名前の画数（**姓名判断の三才**）」と書かれていた。これは事実と違い、要望2で指摘されたそのものだった。加えて同じ注記が二重に出ていた
- **TC・Adv**: 「生まれ持った色」と「その日に選ぶ色」を同じ画面で扱っていた。前者は12色で足りる
- **長押しの説明**: `initLongPressTooltips` が、**指を離したかどうかを見ずに2秒で消していた**。指を置いたままでも消える。さらに `title` を付けたままなので端末側の吹き出しと二重になり、`user-select` の指定が無いためボタン内の文字が選ばれていた

## 解決策

### 1〜6. リニューアル
- タイトルと `<h1>` を `Terre Mer KARTE` に
- Soul Color は**参考表示にとどめ、5色とも手で選び直せる**よう固定（`soul-slots-locked`）を解除。誤っていた注記を書き直し、重複を削除
- `INTAKE_FIELDS` / `fillIntakeFields` / `collectIntakeFields` / `buildIntakeSummary` を追加し、初診の6枠を新設
- `buildTimeOptions()` で 00:00〜23:30 を30分刻み（全49件）に生成
- ラベルを「施術内容」に変更し、`INITIAL_PLANS` に13件を金額つきで登録
- 見出しを `.mark-label` の 🌸 / 🧪 / 🐬 のみに（`title` に意味を持たせる）

### 7. 個人の Soul Color を12色だけに
2か所にあったため、両方から外した。

- 顧客登録フォーム（`#soul-color-palette`）: タブ3つと TC・アドバンスの領域を削除
- カルテの `startSoulColorInlineEdit`: タブを出さず、12色を直接出す

**記録（施術の色）側の TC 14色・アドバンス 17色はそのまま残した。** 生まれ持った色と、その日に選ぶ色は別のものだから。既存データに TC・アドバンスの色が入っていても、名前の引き当ては3体系すべてを見るので、これまでどおり表示できる。

### 8. 📋タブを「カルテ」に
表示（`内容`）と吹き出し（`施術内容履歴`）の両方を **カルテ** に変更。記録を登録するときの「施術内容」（施術の種類と金額）とは別物なので、呼び分けている。

### 9. 押している間ずっと説明を出す
- 指を離す・動かす・割り込まれる、のいずれかで消す。それまでは出したまま
- **押している間だけ `title` を外す。** 付けたままだと端末側の吹き出しが重なる。離せば戻すので、パソコンでマウスを乗せたときの説明は変わらない
- `button` / `label` / `[role="button"]` / `.tab-btn` などに `user-select: none` と `-webkit-touch-callout: none`。**入力欄と記録の本文は対象外**なので、これまでどおり選んでコピーできる
- **説明が出たあとに指を離しても、そのボタンは動かさない。** 読むために押したのであって、押したかったわけではない。🗑️ のように間違って動くと困るものが並んでいるため、安全側に倒した
