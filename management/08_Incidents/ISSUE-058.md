# ISSUE-058: 画面を送ると切り替えのタブが流れていく／タブの取る場所が広い

## 概要
- **発生日**: 2026-08-08
- **分類**: MINOR（v1.39.0）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> このまま下にスライドすると タブグループまで 下に行ってしまうので
> タブグループは固定のままがいいです
> またタブグループの取ってるスペースが大きいので
> 余白 はなるわけないようにかつ 見やすいようにしてください

カルテを下まで読むと、切り替えのタブが画面の外へ出てしまいます。
**別の画面へ移るには、いちど上まで戻さないといけません。**

施術の合間に触るものなので、その往復は手間になります。

## 直したこと

### ① ヘッダーのすぐ下に貼り付ける

```css
.top-control-bar {
    position: sticky;
    top: var(--app-header-h, 64px);
    z-index: 90;
}
```

**ヘッダーの高さは決め打ちにしていません。** 幅や文字の大きさで変わるので、
`ui.js` が実際に測って `--app-header-h` に入れます。
向きを変えたときや文字の大きさを変えたときも、`ResizeObserver` で測り直します。

決め打ちにすると、**環境によって重なるか、隙間が空きます。**

### ② 貼り付いたときに、下が透けないようにする

`main` の左右の余白ぶん外へ広げてから、同じだけ内側に戻しています。
そうしないと、貼り付いた帯の**横の隙間から中身が透けて**流れていきます。

### ③ 場所を詰める（スマホ）

| | 前 | 後 |
|---|---|---|
| タブ全体の内側の余白 | 6px | **3px** |
| ボタンの上下 | 10px | **7px** |
| アイコンの大きさ | 1.2rem | **1.15rem** |
| 帯の下の余白 | 4px | **2px** |

**指の当たる高さは削っていません。** 実測で **44px** です。
押しやすさの目安（44px）をちょうど保っています。

**ヘッダー54px ＋ 帯52px ＝ 106px。** 844pxの画面に対して 1/8 ほどです。

## 検証を書いていて気付いたこと

はじめ、お客様のカルテを開いて下まで送って測ろうとしたところ、
**62pxしか送れず**、判定になっていませんでした。見本のカルテは中身が短いためです。

**「送った」ではなく「送れる余地いっぱいまで送った」**で測るように直し、
中身の長い設定画面を使うようにしました。

## 追記: カルテの中のタブも、上と同じ寸法に揃えた

> タブの大きさの下、向こうのタブグループは少し大きいように思えるので
> 適切な大きさにしてください

上を詰めたことで、**下（カルテの中の 🕐📅📋💴👤✨）だけが大きく残って**いました。
並べて置くものなので、片方だけ大きいと不揃いに見えます。

| | 上 | 下（前） | 下（後） |
|---|---|---|---|
| スマホ・タブ群 | 44px | **57px** | **44px** |
| スマホ・ボタン | 36px | **47px** | **36px** |
| パソコン・タブ群 | 45px | **49px** | **45px** |
| パソコン・ボタン | 35px | **39px** | **35px** |

### 直すときに引っかかったこと

はじめ内側の余白だけ詰めましたが、**5px 残りました。**
測ってみると、アイコンだけ **22.4px（1.4rem）** で、上（18.4px）より大きいままでした。

```css
.detail-subtab-btn .tab-icon { font-size: 1.4rem !important; }
```

**`!important` が付いた別の指定が、後ろで勝っていました。**
新しい指定を足すのではなく、**その指定そのもの**を直しました。

パソコン幅も、ボタンの上下が 10px と 8px で食い違っていたので揃えています。

**目分量で「詰まった気がする」で止めず、両方を測って数字で合わせました。**

## 申し送り

- カルテの中のタブは、**貼り付けてはいません**（上のタブだけ）。両方を貼ると、
  上に占める場所が倍になります。必要でしたら足します
- 寸法は `verify-sticky-tabs.js` が**上下を突き合わせて**見ています。
  どちらかを変えたら、そこで気付けます
