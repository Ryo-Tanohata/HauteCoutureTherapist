# ISSUE-055: 軽いモデルが、渡した希釈の上限を守らないことがある

## 概要
- **発生日**: 2026-08-07
- **分類**: MAJOR（安全に関わる）／**未修正・判断待ち**
- **状態**: **報告のみ**
- **担当**: Claude Code

## きっかけ

> haikuが出ていました
>
> （その前に）AIのモデル名が適切かを見たいです

札が動くようになり、**いま使われているのが `claude-haiku-4-5`** だと分かりました。
「適切か」を言葉で答えても仕方がないので、**同じ入力で何度も作らせて見比べました。**

## 使った入力（1件・実在しない想定のもの）

- 上限 **`maxDilution: "1%"`**
- 使える精油: ラベンダー／ゼラニウム（**妊娠中は避ける**）／マジョラム
- 外した精油: ベルガモット（光毒性）
- 外した基材: スイートアーモンド（**ナッツアレルギー**）
- 申し送り: **「以前、首の付け根を強く押されて頭痛が出たことがある」**
- 経過2件（7/20 肩と首・夜中に目覚める／6/15 腰の張り・歩き方に左右差）

## 結果

### 希釈の上限（1%）を守ったか

| | 上限を超えた回数 |
|---|---|
| **haiku-4-5** | **6回中4回** |
| **opus-5** | **3回中0回** |

実際に出た文です。

```
haiku ①  ラベンダー0.75% ＋ マジョラム0.75% ＝ 1.5%   ← 上限は1%
haiku ②  ラベンダー2%、ゼラニウム1%、マジョラム1%（計4%） ← 上限は1%
opus  ①  ラベンダー2：マジョラム1、ホホバで1%          ← 比で組み、上限内
```

**②の4%は、上限の4倍です。**

### 申し送りを拾えたか

| | ゼラニウムの注意（妊娠） | 「強く押すと頭痛」の申し送り |
|---|---|---|
| **haiku-4-5** | 4回中2回 | 4回中3回 |
| **opus-5** | 3回中3回 | 3回中3回 |

opus は、渡していないことまで足していました。

> - 妊娠の可能性の有無（ゼラニウム使用判断のため）
> - 眠りの浅さが2か月以上続くようなら、一度受診済みか確認を
> - 施術後に運転や仕事の予定があるか

### 数え方の断り

**自動の数え上げは粗いです。** 文中の「%」を全部拾うので、
部位の配分（7割・3割を「%」で書いた回）も混ざります。
ただし**上の①②は目で読んで確かめた**もので、そこは間違いありません。
回数も少ないので、**傾向として読んでください。**

## 見立て

| 使うところ | haiku で足りるか |
|---|---|
| **操作ガイドのチャット** | **足ります。** 説明書から引くだけで、速さが効きます |
| **下ごしらえ・訴えからの提案** | **足りていません。** 上限を超えるのは、好みの問題ではありません |

**この機能は、体質とアレルギーを見て精油を絞り込むところが値打ちです。**
そこで上限を外すなら、絞り込む意味が薄れます。

## 直しかたの案（2つ・どちらも要相談）

### 案A: 用途ごとにモデルを分ける

「下ごしらえ」だけ強いものにし、チャットは軽いままにします。

- **効き**: 大きい。上の比較のとおり
- **代償**: 遅くなる。契約の枠も早く減る
- **手間**: 環境変数を1つ増やすだけ（30分ほど）

### 案B: 出てきた濃度を、アプリ側で確かめる

**モデルに関係なく効く受け皿**です。

上限を超える数字が混じっていたら、画面に「**上限1%を超えています**」と出します。
消しはしません（判断はセラピストのもの）。**気づかず使うことだけを防ぎます。**

- **効き**: 大きい。**どのモデルでも、将来変えても効きます**
- **代償**: ほぼ無し
- **手間**: 半日ほど

### お勧め

**両方。順番は B → A。**

Bは、モデルを変えても・将来 A をやめても効き続けます。
Aは効きますが、**「強いモデルなら大丈夫」という前提に寄りかかる**ことになります。
今日の6回のうち2回は haiku も上限を守っていました。**当たり外れがある**ということです。

## 申し送り

- **「モデルが適切か」は、言葉ではなく同じ入力で回して見比べる。** 今回それで分かりました
- 回数が少ないので、**断定はしていません。** ただ、上限を4倍にした出力が実際に出た以上、
  そのまま配るのは勧められません
- ベルガモット（光毒性で外したもの）に触れた回は、**どちらのモデルでも0**でした。
  外した理由まで伝わっていない可能性があり、これは**プロンプト側の課題**かもしれません
