# ISSUE-084: 取扱説明書が、実物の画面とずれていた

## 概要
- **発生日**: 2026-08-21
- **分類**: 不具合（作業中に発見）＋要望
- **状態**: **対応済み**
- **担当**: Claude Code

## ご要望

> さっきのたたき台の説明をより体系的に簡潔にした説明したものを
> アプリの本番のものに 取説みたいな感じで入れたいです

施術メニューの相談で使った叩き台の説明を、アプリの取扱説明書へ入れる、というご要望です。

## 書こうとして分かったこと

**説明書が、実物の画面と何か所もずれていました。**

| 説明書の記述 | 実物 | いつからずれたか |
|---|---|---|
| カルテのタブは6つ（顧客個人情報／カルテ／施術日・回数／売上・金額合計／施術カレンダー／カラーと星） | **4つ**（📋 🗓️ 💴 ✨）＋ 名前を押すと開く 👤 | ISSUE-073・077 |
| 「画面は5つ」 | **6つ**（📖 が抜けていた） | 以前から |
| 記録に「金額」の欄がある／「実際にいただいた額」を書く | **金額の欄は画面に無い**。施術内容を選ぶと入る | ISSUE-081 |
| 「処方」に使った精油・圧・順番を書く | **処方の欄も画面に無い**。区分ごとのカルテに書く | ISSUE-080 |
| 「アーカイブ」を押す | **名前の行の 📦** | ISSUE-078 |
| 「施術プランの管理」 | 「**⚙️ 施術内容を編集**」 | 以前から |
| 「下ごしらえを作る」ボタンがあります | **既定で止めてある** | ISSUE-083 |
| 「施術日・回数」タブに来店の間隔が出る | 📋 の頭に寄せた | ISSUE-073 |
| 「売上・金額合計」タブ | 💴 金額 | ISSUE-073 |

**画面を直すたびに説明書だけ取り残されていました。** 検証にも見張りが無く、
誰も気づかないまま溜まっていました。

## 直したこと

### ① 説明書を、実物に合わせて体系立て直した

`product/docs/manual.md`。上の表のずれをすべて直したうえで、
**「4. カルテの中身」を組み直しました。**

- **4-1. 2つの層** — 「その人のこと（変わらない）」と「その日のこと（1回ごと）」は別、から始める
- **4-2. その日のこと** — 1件の記録に何が入るか
- **4-3. 「施術内容」と「施術の区分」は、別のものです** — **今回の相談の本題**。
  役割の違いを表にし、**区分は印ではなく入口**（選ぶとその区分の書く欄が開く）ことと、
  10区分それぞれに何を書くかを並べた
- **4-4. 画面に出ていない欄があります** — 施術メニュー・🧪処方・金額はどこへ行ったのか

### ② 困ったときに、2つ足した

- **金額が「金額未定」のまま、直せない**（ISSUE-081 の穴。逃げ道つき）
- **「下ごしらえ」のボタンが見当たらない**（ISSUE-083。戻し方つき）

### ③ ずれを見張るようにした（本題）

`verify-manual.js` に「8. 説明書が、実物の画面とずれていないか」を足しました。

- 実物のタブの数と名前を**画面から拾って**、説明書と突き合わせる
- 消えた画面の名前（施術日・回数／売上・金額合計／顧客個人情報／情報タブ）が
  説明書に残っていないか
- 画面から下ろした金額を、書ける欄として案内していないか

## 気づいたこと

- **説明書は、画面より先に古くなる。** 画面を直したときに説明書を直す決まりが無く、
  検証も見ていなかったので、9か所ずれても誰も気づかなかった
- **見出しへのリンクは、綴りの規則に合わせること。**
  `#4-3-施術内容と施術の区分は-別のものです` と書いたが、`、` は落ちて `-` にならない。
  `headingNumber()` が拾う **`#4-3` の形が確実**（実際に押して着くことを確認した）
- **見張りは「効くこと」まで確かめる。** 通っただけでは、何も見ていない見張りと区別がつかない
