# ISSUE-050: APIキーの入れ物が2つあり、片方に入れても、もう片方は「無い」と言う

## 概要
- **発生日**: 2026-08-07
- **分類**: MINOR（v1.32.0）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> apio 設定するところが フローティング チャットのところと設定の2つありますが
> 統一したいです どうすると良いですか おすすめですか
>
> 設定 タブに統一してください

## いままでどうだったか

同じ「APIキー」を、**別々の場所に、別々に覚えていました。**

| | 置き場所 | 使えるキー | 使うところ |
|---|---|---|---|
| **⚙️ 設定** | `therapist_ai_api_keys` | **Anthropic と Gemini** | 星詠み・下ごしらえ |
| **チャットの中** | `aurora_gemini_api_keys` | **Gemini だけ** | 操作ガイドの返事 |

**片方に入れても、もう片方は「キーがありません」と言います。**
入れる場所が2つあると分かるまで、原因の見当がつきません。

## どちらへ寄せたか、その理由

**設定側へ寄せました。** 逆ではありません。**設定側のほうが出来がよいため**です。

| | 設定側 | チャット側 |
|---|---|---|
| Anthropic のキー | ✅ 使える | ✕ Gemini のみ |
| 複数登録して、駄目なら次を試す | ✅ | ✕ |
| 上限に当たったキーを後回しにする | ✅ | ✕ |
| 使えなくなったモデルを避ける | ✅ | ✕ |

チャット側は、これらを**何も持っていませんでした。**
寄せたことで、**チャットもこの手当てを受けられます。**

## 実装

### 1. 返事の作り方を、アプリ側の仕組みに寄せた

チャットは自前の Gemini 呼び出しをやめ、`generateWithOwnKey()`（`ai-client.js`）を通します。

**部品の中身は直接いじっていません。** `FloatingChat` はもともと
`config.generateReply` という差し込み口を持っていたので、そこへ渡しています。
**この部品は他でも使い回せるものなので、アプリ固有の事情を中に埋めない**ようにしました。

### 2. チャットの設定タブを、案内に差し替えた

`config.externalKeysHtml` を渡すと、入力欄の代わりに案内が出るようにしました。

> キーは **⚙️ 設定 →「🤖 AI の設定」** で登録します。

入力欄が2つあること自体を無くしています。
キーを操作する処理は、**入力欄が無いときは結ばない**ようにしました（`if (els.addKeyBtn)`）。

### 3. すでに入っているキーを、黙って移した

**入れ直しをお願いしないため**です。

```js
// 移し終えてから消す。途中で失敗しても、元が残っているようにする
found.forEach((k) => { if (!already.includes(k)) { addApiKey(k); } });
localStorage.removeItem(LEGACY_CHAT_KEYS);
```

古い単数の形（`aurora_gemini_api_key`）も拾います。
**先に消してから移すと、途中で失敗したときにキーが消えます。** 順番を逆にしました。

## 作業中に見つけたこと

**読み込む先の道を1つ間違えていました。**

```js
from '../../app/ai-client.js'      // ← 誤り。vendor/app/… を指していた
from '../../../app/ai-client.js'   // ← 正しい
```

**チャットが丸ごと出なくなりました。** 画面のエラーとしては出ず、
**吹き出しのボタンごと消える**という形でした。

検証で「吹き出しが見つからない」と落ちて気付きました。
**目で見て確かめていたら、「チャットを開かなかっただけ」と思って見逃していた**はずです。

## 検証結果

`management/09_Verification/verify-keys-unified.js`

| 調べたこと | 結果 |
|---|---|
| チャットの設定タブに、キー入力欄が無いか | **無い** |
| 設定画面への案内が出ているか | **出ている** |
| **前にチャットへ入れていたキーが移るか** | **3本とも移った**（配列2本＋古い単数1本） |
| 古い置き場が片付いているか | **片付いた** |
| **もう一度開いても、二重に増えないか** | **3本のまま** |
| 設定側に入れたキーを、チャットが見ているか | **見えている**（Anthropic のキーで確認） |
| 画面のエラー／守りに弾かれたもの | **0件** |

既存のもの（`verify-csp.js` / `verify-manual.js`）も通っています。

## 申し送り

- **キーが1本になったので、片方だけ止めることはできません。** いま使い分けが
  必要でなければ、単純なほうがよいという判断です
- チャットの返事が **Anthropic のキーでも作れる**ようになりました。
  提供元が変わると、**口調が少し変わる**可能性があります
- `llm-gemini.js`（チャット自前の Gemini 呼び出し）は、**他の使い回し先のために残して**あります。
  このアプリからは呼ばれません
