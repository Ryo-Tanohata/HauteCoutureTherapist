# ISSUE-081: 金額の欄も、画面から下ろした

## 概要
- **発生日**: 2026-08-16
- **分類**: 要望（サロンからのご要望）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> 金額を直すところは まあ 今のところ 不要にしときます
> セラピストの要求に合わせます

ISSUE-080 では「値引きや追加の日に直せなくなる」ことを理由に**畳んで残す**形にしましたが、
実際に使うセラピストの側から不要とのご判断です。

## 直したこと

`▸ 💴 金額を直す` の畳みを、2つの画面（予約・カルテ）から外しました。

**入れ物は隠して残して**あります。施術メニュー・🧪処方と同じ扱いです。

- **金額はプランを選んだときに入ります**
- 入れ物ごと消すと、**プランから来た値の行き先が無くなり、金額をどこからも書けなくなります**

記録のカードでは、これまでどおり施術内容の横に金額が出ます。
💴 の累計も、これまでどおり動きます。

## 検証結果

`management/09_Verification/verify-categories.js`（第4節を差し替え）

```
=== 4. 金額も下りているか
  金額の欄が出ていない            ✅
  金額の入れ物は残っている        ✅
  「金額を直す」も無い            ✅
   プランを選んだあと: {"want":"0","type":"無料カウンセリング","amount":"0"}
  プランから施術メニューが入る    ✅
  プランから金額が入る            ✅
=== 5. カルテ側でも同じか（画面は2つある）  ✅
  ぜんぶ通りました
```

**「欄が消えたか」だけでは足りません。** プランを実際に選んで、
**見えない入れ物にちゃんと入るところ**まで見ています。
ここが入らないと、金額を書く道が1本も無くなります。

戻りがないことも確認済みです。
`verify-clash` / `verify-booking` / `verify-csp` / `verify-kana-auto` /
`verify-personal-info` / `verify-accordion` / `verify-sticky-tabs` / `verify-demos` — **すべて通過**。

## 申し送り

- **金額を入れる道は「プランを選ぶ」だけ**になりました。
  値引きや追加でその日だけ違う金額にはできません。必要になったら、
  この畳みを戻すのがいちばん早い（`ISSUE-080` のコミットに形が残っています）
- プランを選ばない日は「金額未定」。**💴 の累計では 0 として数えます**（ISSUE-072 の申し送り）
- 予約の画面の `<details>` は「詳細メモ」1つに戻りましたが、
  **id で指す形は残してあります**（また増えたときに同じことが起きないように）
