# ISSUE-079: よみがなに漢字が入る／ソウルカラーの自動計算を登録画面からも外した

## 概要
- **発生日**: 2026-08-16
- **分類**: 不具合（サロンの画面から発見）＋要望
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> ソウルカラーの自動計算をなくして名前の読み仮名を自動で入力するようにしたいのですが
> 名前の読み方の自動入力はどのように実装できるかを教えてください

スクリーンショットのよみがな欄に、**「田中 圭」と漢字が入っていました。**

## 分かったこと

**よみがなの自動入力は、すでに入っていました。** 作りは変えず、壊れていた1点を直しています。

### なぜ漢字が入るのか

漢字から読みは引けません（「圭」が「けい」か「かど」かは字面では決まらない）。
そこで**変換を確定する前に打った読みを控える**作りにしてあります。

ところが **変換候補を選ぶと `compositionupdate` がもう一度、
今度は変換後の漢字で流れてきます。** 最後の値を読みとして採っていたので、
ひらがなが漢字で上書きされていました。

合成イベントでスマホの打ち方を真似て、直す前の版で再現しました。

```
① 変換せず、ひらがなのまま確定
   氏名: "たなか"  →  よみがな: "たなか"     ← 正しい
② 漢字に変換して確定
   氏名: "田中"    →  よみがな: "田中"       ← 漢字が入る（これ）
```

## 直したこと

### ① 読みとして採るのは、かなに見えているあいだだけ

```
た → たな → たなか → 田中
                ↑ここを覚える（「田中」は無視）
```

### ② 拾えないときは、空のままにする

**予測変換で一足飛びに確定**すると、かなを1文字も見ないまま漢字が来ます。
このとき読みは分かりません。

読みが確定した字より短いときは「拾えていない」と見なし、**空にします**。
**当て推量の読みが入るくらいなら、空けて手で入れていただくほうがよい**ためです。
貼り付けも同じ扱いです（これは元からそうなっていました）。

### ③ ソウルカラーの自動計算を、登録画面からも外した

ISSUE-077 でカルテ側から下ろし、今回サロンのご指示で登録画面からも外しました。
**5色は下の丸を押して手で選びます。**

計算そのもの（`soul-color.js`）は消していないので、戻したくなれば呼び出しを足せます。

### ④ デモを直した

登録のデモが、消した自動計算の箱を指していました
（`#input-soul-auto`／「名前と生年月日から5色が出ました」）。
**押す相手が消えると黙って飛ばされる**ので、5色の丸を指すよう向け直しています。

## 検証結果

`management/09_Verification/verify-kana-auto.js`（新規）

```
=== 1. 変換せず確定            "たなか" → "たなか"        ✅
=== 2. 漢字に変換して確定      "田中"   → "たなか"        ✅
   よみがなに漢字が混じっていない                        ✅
=== 3. 姓と名を続けて          "田中 圭" → "たなか けい"  ✅
=== 4. 予測変換で一足飛び      "田中"   → ""             ✅
=== 5. 貼り付け                "山田 花子" → ""          ✅
=== 6. 手で直したら上書きしない                          ✅
=== 7. 自動計算が登録画面から消えたか／丸は5つ残る       ✅
  ぜんぶ通りました
```

**「かなが入るか」だけでは足りません。** 変換したときに漢字が入らないこと、
そして**拾えないときは空のままにすること**まで見ています。
空を確かめないと、**当て推量の読みを入れる実装でも通ってしまいます**。

戻りがないことも確認済みです。
`verify-personal-info` / `verify-csp` / `verify-accordion` / `verify-cautions` /
`verify-booking` / `verify-clash` / `verify-sticky-tabs` / `verify-demos` — **すべて通過**。

## 申し送り

- **検証は合成イベントです。** Gboard などの実機で同じ順に流れる前提で作っています。
  **実機でもう一度お確かめください**（よみがな欄がひらがなになるか）
- **拾えないときは空**です。貼り付け・予測変換・変換履歴からの入力では入りません。
  手で入れていただくか、**一度消して打ち直す**と入ります
- 辞書（kuromoji.js・十数MB）やAIに聞く方法は採っていません。
  AIは**氏名を生成AIへ送ることになる**ため（いまは送っていない／ISSUE-049）
- **ソウルカラーは、もうどこでも自動計算しません。** 登録時は手で5色を選びます
