# ISSUE-087: 貼り付いた行のアイコンが、途中から2つずつになる

## 概要
- **発生日**: 2026-08-21
- **分類**: 不具合（サロンの画面から発見）
- **状態**: **対応済み（配信前）**
- **担当**: Claude Code

## 症状

> 3行目になってもアイコンが4つ横並びで表示したいです

貼り付いた行（ISSUE-086）の選んだアイコンが、**途中から2つずつ**になっていました。

いただいた2枚を見ると、はっきり分かれています。

| | 合計の字 | 並び |
|---|---|---|
| 6つ選んだとき | `60,000円` | 4 ＋ 2 |
| 7つ選んで「都度」が混ざったとき | `60,000円 ＋ 未入力` | **2 ＋ 2 ＋ 2 ＋ 1** |

## 原因

**折り返しに任せていた。**

アイコンの並びを `display: flex; flex-wrap: wrap` にし、`flex: 1 1 auto` で
残った幅を使う形にしていました。

そのため、右の合計に「**＋ 未入力**」が付いて長くなると、
**その分だけアイコンの側が痩せて**、1行に入る数が減っていました。
選んだ数ではなく、**合計の字の長さ**で並びが変わる作りでした。

## 直したこと

`.menu-fold-state` を、**4列の格子**にしました。

```css
display: grid;
grid-template-columns: repeat(4, auto);
justify-content: end;
flex: 0 0 auto;      /* 縮ませない */
```

- **横は必ず4つ。増えるのは行数だけ**になります
- 合計の側を `flex: 1 1 auto` にして、長くなったら**そちらが折り返す**ようにしました
  （こちらを縮まない扱いにすると、代わりにアイコンが痩せます）
- 何も選んでいないときの「まだ選んでいません」は、`grid-column: 1 / -1` で4列ぶん使います

## 検証結果

`management/09_Verification/verify-categories.js` の「2.6」

**16個ぜんぶ押した状態**（金額が「都度」のものも入るので「＋ 未入力」が付く）で見ています。

| 見たこと | 結果 |
|---|---|
| 合計が長いほうで試せている（＋未入力が付いている） | ✅ |
| 最後の行以外は、どこも4つ（`[4,4,4,4]`） | ✅ |
| 要約の行がはみ出していない（0px） | ✅ |
| 画面が横にずれていない（0px） | ✅ |

**幅を変えても同じ**でした。390px / 360px / 320px のいずれも `[4,4,4,4]`、はみ出し 0px。

あわせて `verify-booking` / `verify-card-rows` / `verify-accordion` / `verify-clash` /
`verify-preview-bundle` も通ることを確認しました。

## 気づいたこと

- **`flex-wrap` は「何個ずつ」を約束しない。** 決まった数で並べたいなら格子にすること
- **痩せるのは、縮んでよい側。** 両方を `flex: 1 1 auto` にすると、
  長くなったほうに押されて短いほうが潰れる。**どちらを折り返させるかを決める**
- **試すのは、いちばん長い状態で。** 6つ・短い合計では 4＋2 に見えていて、
  「＋ 未入力」が付く組み合わせで初めて崩れた。
  検証も**16個ぜんぶ押した状態**で見ている
