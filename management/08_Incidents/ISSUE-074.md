# ISSUE-074: アーティファクトの束ね直しが、どこにも残っていなかった

## 概要
- **発生日**: 2026-08-14
- **分類**: 保守（作業中に気づいた）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / きっかけ

> まずはアーチファクトのURLで確認したいです

サロンに渡しているアーティファクト（1ファイルのプレビュー）は、
**リポジトリの外にある使い捨ての場所で束ねていました。**

そのため、
- **どう束ねたかがどこにも残らない**（毎回、思い出しながら書き直す）
- モジュールが増えても**気づけない**（`ai-route.js` と `chat-visibility.js` は
  前回の手順に入っていなかった）
- **束ね直しを忘れると、古いアプリが静かに配られる**

実際、公開されていたのは **2026-08-05 のもの**で、
ISSUE-059〜073 が1つも入っていませんでした。

## どうやって気づいたか

サロンから「アーティファクトのURLを教えてほしい」と言われて開こうとしたとき、
**手順が手元に無い**ことに気づきました。
使い捨ての場所を探して、8月2日に書いた古い版が見つかった、という経緯です。

**残っていなければ「無い」のと同じ**です。

## 直したこと

### ① 束ねる手順を、リポジトリに置いた

`scripts/build-artifact-preview.js`

```bash
node scripts/build-artifact-preview.js [出力先]
```

やっていること。**アプリのコードは書き換えません。**

- CSS と `<style>` を取り込む（ツアーの覆いが入っているかを確かめてから）
- 画像を data URI にする（Artifact は外のホストへ通信できない）
- モジュールの `import` / `export` を落として、順に連結する
- **トップレベル名の衝突を、束ねる前に見つける**（あると丸ごと動かない）
- サーバーが要る `/api/*` を、ブラウザ内の代役に差し替える

代役では、**同期だけは黙って成功扱いにしません**（503 を返します）。
「同期できた」と出たまま何も渡らないのが、いちばん困る嘘のためです。

### ② 束ねたものを確かめる手順も置いた

`management/09_Verification/verify-preview-bundle.js`

## 申し送り

- **アプリにモジュールを足したら、`MODULES` の並びにも足すこと。**
  並びは**前のものを後ろが使う**順です。足し忘れると、
  そのモジュールを使う画面だけが静かに動かなくなります
- **配信のたびに束ね直すこと。** 忘れると、アーティファクトだけが古くなります
- プレビューでできないこと（本物との違い）。**サロンに伝えること**
  - **サロンの置き場への同期**（503 を返します）
  - **AIの生成**（下ごしらえ・訴えからの提案）。星詠みは生成済みの文章が出ます
  - **控えの書き出し（📤）**。Artifact 側がダウンロードを止めるため動きません
  - 書いた内容は**そのブラウザの中だけ**に残ります
- アーティファクトのURLは `https://claude.ai/code/artifact/20c0b889-3de8-47b2-8ae6-2262b2f92114`。
  **同じURLへ上書きすること**（新しく作ると、サロンの手元のリンクが古いままになる）
