# ISSUE-089: カルテの見出しが、同じものを二度並べていた

## 概要
- **発生日**: 2026-08-28
- **分類**: 不具合（サロンの画面から発見）
- **状態**: **対応済み（配信前）**
- **担当**: Claude Code

## ご指摘

> ここの診察のアイコンは良いのですが、診察内容も文字で示していますか?
> であれば分かりやすく見せるためにどうすれば良いですか?

**はい、文字でも出していました。** そこが読みにくさの元でした。

## 何が起きていたか

要約の行を、こう組み立てていました。

```js
${buildCategoryIconsHtml(r)}${escapeHtml(recordTypeLabel(r))}
```

| | どこから引いていたか |
|---|---|
| **アイコン** | その記録の**区分**（書く欄）。10個まで |
| **文字** | 押した**施術内容の名前**を「・」でつないだもの。16個まで |

**別々の一覧なのに、指しているものはほぼ同じ**です。
ISSUE-085 で施術内容をひと並びにまとめたとき、`type` に名前をつないで入れるように
したのですが、**アイコンの側をそのままにしていました。**

16個押した日は、こうなります。

```
📈🍀🤙🦄🐾🌈🦋📝📙 初診・再診・月set・延長・靈氣・月・靈氣・週・A.C・
counseling・ボランティア・item・講座・W.S・その他・monitor・TEL・color
```

**5行を占めて、金額が下へ押し出されていました。**

いただいた1枚目が読みやすかったのは、**まとめる前に書かれた記録**だったためです。
文字が「無料カウンセリング」というプラン名1つで、アイコンと重なっていませんでした。

## 直したこと

**アイコンと名前を対にした札**を、1つの施術内容につき1つ出します（案A）。

```
🫶 再診　⏱️ 延長　🍀 item     20,500円
```

- 二度並ぶことがなくなります
- **どのアイコンが何なのかが、その場で分かります**（以前は分かりませんでした）
- **4つ以上のときは、先頭3つと「ほか N」**にまとめます（`SUMMARY_MENU_LIMIT = 3`）
- **畳んだぶんは、カードを開けば全部出ます**

```
🌱 初診　🫶 再診　📅 月set　ほか 13     102,500円
```

### まとめる前の記録は、そのままです

`menu` を持たない記録は、**そのとき書かれた名前をそのまま**札1つとして出します。
「無料カウンセリング」は「無料カウンセリング」のまま。書き換えていません。

### メニューから消された項目があるとき

`recordMenuItems()` は、**1つでも引けなければ空を返します。**
消された項目の札だけが黙って消えるより、**保存してある `type`（名前をつないだもの）に
まるごと落ちる**ほうが確かだからです。消えた項目の名前は、そちらにしか残っていません。

## 気づいたこと

- **`buildCategoryIconsHtml` は `initApp` の中にあり、外からは見えない。**
  同じ名前の関数が2つの入れ物に分かれている。最初これを呼んで、
  一覧が丸ごと描かれなくなった（例外は握り潰されるので、画面が空になるだけ）
- **検証で「再診」を含むカードを絞ったら、16件のカードも当たった。**
  中身の字で絞ると取り違える。**日付のように、そのカードにしか無いもので指すこと**
- **足したものと、もとからあったものの両方を見ること。** ISSUE-085 で `type` の
  中身を変えたのに、隣のアイコンをそのままにしていた。片方だけ直すと重なる

## 申し送り

- **札の数は `SUMMARY_MENU_LIMIT`（いま3）。** 変えるならここ1か所
- 📋 と 💴 は**同じカードの部品**を使っている。片方だけ直すことはできない
