# ISSUE-036: ソウルカラーの丸に、押したときの処理が積み重なる

## 概要
- **発生日**: 2026-08-06（ISSUE-032 の作業中に発見）
- **分類**: 潜在的な不具合（見た目には出ていなかった）
- **状態**: **修正済み**（ISSUE-032 と同じ変更に含めて修正）
- **担当**: Claude Code

## 症状

`initSoulColorSlotSelector()` は、登録画面を開くたび・色を入れ直すたびに呼ばれる。丸への結び付けが `addEventListener` のため、**呼ばれるたびに押したときの処理が1つずつ増えていた**。

```js
slots.forEach((slot, idx) => {
    slot.addEventListener('click', () => { ... });   // 呼ばれるたびに増える
});
```

**見た目には出ていなかった。** 増えた処理はそれぞれ自前の「選んだ色」を持っており、最後に結んだものが最後に描くため、表示は正しくなる。ただし画面を開くほど増え続ける。

## 経緯（誤診の記録）

ISSUE-032 の検証で「5色を入れたあと、手で選び直せない」という結果になり、**この積み重なりが原因だと見立てた**。

しかし実際は**検証側の誤り**だった。選び直しに使った色（`7-purple`）が、たまたま**もともと1色目に入っていた色と同じ**で、押しても何も変わらなかっただけだった。別の色（`1-red`）で試すと、修正を外した状態でも正しく選び直せた。

**不具合と見立てたものが、自分の検証の誤りだった。** 変更を一度外して確かめたことで分かった。

## 解決策

見た目には出ていないが、増え続けるのは正しくないため、**予防として**残した。節ごと差し替えて、前の結び付きを断ってから付け直す。

```js
slotsContainer.querySelectorAll('.soul-slot').forEach((el) => {
    el.replaceWith(el.cloneNode(true));
});
const slots = slotsContainer.querySelectorAll('.soul-slot');
```

## 教訓

**「動かない」と思ったら、まず検証のほうを疑う。** 特に「同じ値を入れて、変わらないことを変わらないと言っている」type の誤りは、結果だけ見ると不具合と区別がつかない。変更を外して再現するかを確かめるのが早い。
