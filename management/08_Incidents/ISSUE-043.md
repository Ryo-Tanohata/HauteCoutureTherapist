# ISSUE-043: ブラウザ側の守りが無く、書いた文字がそのまま動く形で画面に入っていた

## 概要
- **発生日**: 2026-08-07
- **分類**: MAJOR（v1.27.0）
- **状態**: **配布済み**（2026-08-07 / `0bc1a1e`）
- **担当**: Claude Code

## 症状 / 要望

> 一般的なセキュリティに比べて このアプリではどんな感じですか
>
> あなたにお任せします。またこれはレポートに残してください

見比べてみると、**暗号のかけ方は同じ規模のアプリの平均よりかなり上、
周りの守りは薄い**という形でした。「金庫は立派だが、部屋に鍵がない」状態です。

薄かったところのうち、**いま入れても他に影響しない3つ**を直しました。

### 1. 書いた文字が、そのまま動く形で画面に入っていた

訴え・施術内容・メモ・電話番号・紹介者・顧客No.・生年月日の**8か所**で、
入力した文字を**そのまま HTML として**画面に入れていました。

たとえば訴えの欄に `<img src=x onerror="...">` と書くと、字として出るのではなく
**その場で動きます。** 書くのはサロン自身なので当面の実害はありませんが、

- 置き場をまたいで**他の端末にも飛ぶ**
- 動いた側は `localStorage` を読めるので、**合言葉ごと持っていける**

という形になっていました。守るべきものの近さを考えると、放っておけません。

### 2. ブラウザ側の守り（CSP）が無かった

`_headers` が無く、ブラウザへの指定がゼロ。**1 が起きたときに、止める層がありません。**

### 3. 外のCDNから、実行されるものを読んでいた

```html
<script src="https://cdn.jsdelivr.net/npm/marked/marked.min.js"></script>
```

版を指定していないため、**その先が差し替われば、差し替わったものがそのまま動きます。**
配る側を握られたら、カルテも合言葉も渡ります。

## 直したこと

| | 前 | 後 |
|---|---|---|
| 画面への出し方 | 8か所が素通し | すべて字として出す（`escapeHtml`） |
| ブラウザの守り | 無し | `product/_headers` に CSP ほか6つ |
| marked | 外のCDN・版の指定なし | **自前で持つ**（v12.0.2 を同梱） |
| ページの中の script | 1か所あった | **全部外に出した**（`js/app/aurora-boot.js`） |
| 置き場の返事 | 種類の指定のみ | `nosniff` を追加 |

ページの中の script を全部追い出したので、CSP に `'unsafe-inline'` を入れずに済みました。
**ページの中に書かれたものは、もう動きません。**

## 検証結果

`management/09_Verification/verify-csp.js`。本番と同じ守りを付けて配り
（`serve-with-headers.js` が `_headers` をそのまま読む）、実物の画面を一巡しました。

手で書ける**11の欄すべて**に `<img src=x onerror=...>` を入れ、
一覧・カルテの6つのタブ・カレンダー・日付を押したあと、の**10画面**を見ています。

| 調べたこと | 結果 |
|---|---|
| 守りに弾かれたものが出ないか（画面が壊れていないか） | **0件** |
| 画面のエラー | **0件** |
| marked が自前のもので動くか | **動いた** |
| 10画面すべてで、書いたものが動く形になっていないか | **すべて字のまま** |
| 書いたものが読めるか（消えていないか） | **読める** |
| 同期の突き合わせが壊れていないか（`verify-fieldmerge.js`） | **通った** |

### 途中で見つかったこと

grep で8か所を直したあと検証したら、**9か所目が残っていました。**
`buildRecordDetailsHtml` の共通部分で、grep の形に当てはまらない書き方でした。

```js
const body = html || (filled ? value : '未記入');   // ← ここ
```

**目で探すより、実際に入れて画面を一巡するほうが確実**でした。
この時点で CSP は既に入っていたので、**入り込みはしたが動きはしませんでした**（守りが効いた形）。

## 追記（同日・第2段）: 外から読む実行を、ゼロにした

申し送りにしていた **esm.run** を片づけました。

操作ガイドのチャットは Gemini の SDK を `import('https://esm.run/@google/genai')` で
外から読んでいました。使っていたのは `generateContent` **ひとつだけ**で、
アプリの別のところ（`ai-client.js`）は既に同じ窓口を**直に叩いて**います。
同じ形に書き換え、SDK ごと外しました。

これで `script-src` から外の名前が消えます。

```
前: script-src 'self' https://esm.run https://cdn.jsdelivr.net
後: script-src 'self'
```

**外から読み込まれて動くものは、もうありません。**（外へ出るのはフォントの指定だけ。
これは実行されるものではありません）

あわせて `_headers` に4つ足しました。

| | 中身 |
|---|---|
| `Cross-Origin-Opener-Policy: same-origin` | 他所のページから、このページの窓を覗かせない |
| `Cross-Origin-Resource-Policy: same-origin` | 他所のページから、中身を読み込ませない |
| `X-Robots-Tag: noindex, nofollow` | 検索に載せない。入口を探せる場所に置かない |
| `Cache-Control: no-store`（画面のみ） | 共用のパソコンで、閉じたあと戻るボタンで中身が出るのを避ける |

検証は `verify-csp.js` に**2つ足しました**。

- **外へ取りに行った先を全部記録し**、実行されるものが外から来ていないことを見る
- 操作ガイドのチャットを開き、壊れていないことを見る

| 調べたこと | 結果 |
|---|---|
| 外へ取りに行った先 | **fonts.googleapis.com のみ**（実行されるものは0） |
| チャットを開いたときのエラー | **0件** |
| 弾かれたもの | **0件** |
| 画面の一巡（10画面） | **すべて字のまま** |

## まだ残っていること（申し送り）

| | 中身 | なぜ今やらないか |
|---|---|---|
| **合言葉が端末に平文で残る** | 自動同期のため | 消すと毎回入力になる。サロンの使い方と相談 |
| **鍵づくりの重さ** | 21万回。OWASP の現行推奨は60万回 | **回数を変えると鍵が変わり、いま置いてあるものが開けなくなる。** 版番号を付けた移し替えが要る |
| **塩が固定値** | 端末をまたぐ設計上こうなる | 変えると同上 |
| **回数制限が無い** | 合言葉の総当たりを弾けない | Cloudflare 側の設定で入れられる |
| **控えが無い** | 置き場が壊れたら端末のぶんだけ | 運用の相談（悪意より事故のほうが確率は高い） |
| **style="" が225か所** | そのため `style-src` に `'unsafe-inline'` が要る | 外に出すのは別の作業 |
