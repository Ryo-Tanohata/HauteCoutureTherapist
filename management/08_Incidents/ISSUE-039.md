# ISSUE-039: 一覧に出す呼び名を、設定で選べるようにする

## 概要
- **発生日**: 2026-08-07
- **分類**: MINOR (v1.25.0)
- **担当**: Claude Code

## 症状 / 要望

> 氏名とニックネームはアプリ上でどちらを優先して出すかは選べるようにしてください

## 根本原因

ISSUE-032 でカレンダーの札を**ニックネーム優先に決め打ち**した。そのときはご指示どおりだったが、

- 普段の呼び名で並べたい日と、氏名で確かめたい場面は**どちらもある**
- 決め打ちだと、変えたくなるたびにこちらへ頼むことになる

選ぶのはサロンであって、コードに固定するものではなかった。

## 解決策

⚙️ 設定 → 📝 記録の設定 に **「一覧に出す呼び名」** を追加した。ニックネーム（既定）／氏名 の切り替え。

効くのは**3か所**。

| 場所 | ニックネーム | 氏名 |
|---|---|---|
| 顧客一覧 | はなちゃん（下に氏名） | 山田 花子（下によみがな） |
| カレンダーの札 | はなちゃん | 山田（スマホは姓） |
| その日の一覧 | はなちゃん | 山田 花子 |

**ニックネームを入れていない方は、どちらを選んでも氏名で出る。**

### カルテの見出しは変えない

どちらを選んでも、**カルテの頭は氏名が主のまま**（隣にニックネームの札）。ISSUE-031 で決めたとおり、**カルテとして残すのは氏名**だからである。この設定は「一覧での呼び方」であって、カルテの記載を変えるものではない。

### 切り替えたら、その場で描き直す
設定を変えたのに一覧が前のままだと、効いたのかどうか分からない。顧客一覧・カレンダー・開いているカルテを描き直している。

## 変更ファイル
- `product/js/app/data.js`（`getNamePreference` / `saveNamePreference`）
- `product/js/app/ui.js`（`displayNameOf`、札とカードと一覧、設定のトグル）
- `product/index.html`（設定の欄）
