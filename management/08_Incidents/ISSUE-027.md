# ISSUE-027: 設定画面の整理、顧客No. の固定、および Vercel の名残の撤去

## 概要
- **発生日**: 2026-08-06
- **分類**: MINOR (v1.18.0)
- **担当**: Claude Code

## 症状 / 要望

1. **カラー設定の画面が分かりづらい。** カラーマスターの編集は実務で使っておらず、いまは無くてよい。名前を変えて、こまごまとした設定だけできるようにしたい。
2. **顧客No. が手で書き換えられる。** 自動採番されているのに入力欄が編集可能で、人が触れてしまう。
3. **「はじめての設定」（置き場のつなぎ方）は開発者だけが知っていればよく、セラピストには不要。** ふだんは出さないでほしい。
4. **Vercel 関係は消してよい。**

## 根本原因

1. 「カラー設定」は色マスターの CRUD 画面として作られていたが、実際に使うのはサロン名・アドバンスカラーの既定セットなど、こまごまとした設定のほうだった。画面の名前と中身がずれていた。
2. `input-customer-no` に `readonly` が無く、値だけを JS で入れていた。表示専用のつもりが、入力欄として振る舞っていた。
3. 置き場のつなぎ方（合言葉の決め方、Cloudflare の設定）は最初の1回だけ必要な手順で、日々のカルテ作業には現れない。常時表示だと、毎回読み飛ばす画面になる。
4. Vercel から Cloudflare へ移したあとも、配信設定と依存が残っていた。

## 解決策

### 1. 「カラー設定」→「⚙️ 設定」
- 画面名を **⚙️ 設定** に変更
- カラーマスターの追加・編集・削除を撤去
- 中身を、使う頻度の順に折りたためる `.settings-group` へ組み直し
- `getColorMasters` は**読み取り専用として残した**（後述）

### 2. 顧客No. を触れないようにする
- `readonly` を付け、`.form-control[readonly]` で「触れない欄」と分かる見た目にした
- 採番を「登録済みの最大値 + 1」に変更。以前は件数から採っていたため、顧客を消すと番号が戻り、同じ番号の人が二人できる恐れがあった

### 3. 「はじめての設定」を、ふだんは出さない
`#salon-setup` を既定で隠し、必要なときだけ開く形にした。

### 4. Vercel の撤去
- `api/sync.js`（Vercel Blob 版の窓口）、`vercel.json`、`.vercelignore`、`@vercel/blob` 依存を削除
- `vercel-sync.js` を `salon-store.js` へ改名
- R2 のバインディング名を `SALON_BLOB` から **`SALON_STORE`** へ変更（役割で呼ぶ）
- 実態と合わなくなっていた説明文を修正（塩の作り方、静的配信の例）
- 合言葉の保存キーの旧名 `therapist_vercel_cfg` は**読むだけ残した**（後述）

### 5. コミットの署名
GitLab への push は持ち主の資格情報で行っているのに、コミットの表示名だけが別人になっていた。`loutarma <loutarma@gmail.com>` に統一した。

## 変更ファイル
- `product/index.html`（⚙️ 設定、顧客No. の `readonly`、`#salon-setup` を既定で非表示）
- `product/js/app/ui.js`（設定画面の組み直し、`lockCustomerNo`）
- `product/js/app/data.js`（`nextCustomerNo`、カラーマスターの編集系を削除）
- `product/css/index.css`（`.settings-group`、`.form-control[readonly]`、`.field-locked-note`）
- `product/js/app/salon-store.js`（改名。旧キーの読み取り、説明文の修正）
- `api/sync.js` / `vercel.json` / `.vercelignore`（削除）

## 指示どおりにしなかったところ（申告）

### カラーマスターを「完全に消す」とは言われたが、読み取りだけ残した
既存の記録は色をキー（`7-purple` など）で持っており、`getColorMasters` を消すと**過去のカルテが色の名前を失い、生のコードで表示される**。編集の口はすべて塞いだうえで、読み取りだけ残している。

### 合言葉の旧保存キーを読む処理を残した
名前を変える前に合言葉を入れた端末がまだあり得る。消すと、その端末は更新した瞬間に「まだつながっていません」に戻り、合言葉を入れ直すことになる。読むだけで、新しく書き込むことはない。

### README と management の Vercel 記述は残した
「なぜ Vercel から移したか」は名残ではなく、いま Cloudflare を使っている理由そのもの。消すと後から判断の根拠が追えなくなるため、経緯として残した。
