# ISSUE-052: `npm audit` が高深刻度4件。中身は使っていない部品だった

## 概要
- **発生日**: 2026-08-07
- **分類**: MINOR（v1.34.0）／**保守**
- **状態**: **対応済み（0件）**
- **担当**: Claude Code

## 症状 / 要望

> npm audit
> 4 high severity vulnerabilities

サロンのPCで立ち上げようとしたところ、警告が出た。

| 出ていたもの | 深刻度 | 経路 |
|---|---|---|
| `brace-expansion` | high | 依存の依存 |
| `immutable` | high | **`browser-sync`** → `browser-sync-ui` |
| `shell-quote` | high | **`concurrently`** |
| `fast-uri` / `hono` | high / moderate | Agent SDK の依存 |

## まず、どこに効く話かを分けた

**どれも、サロンに配られるものには入っていません。**

配っているのは `product/` の中身だけで、`node_modules` は含まれません（ISSUE-049 で確認済み）。
つまり**お客様のカルテに届く経路は、この警告には無い**。

効くのは「**サロンのPCで立ち上げたとき**」だけ。しかも中身は
いずれも **DoS（動かなくする）** 系で、悪意ある入力を自分で食わせない限り起きません。

**急ぎの危険ではない。** ただ、警告が出たままだと本当に危ないものが埋もれるので、片づける。

## 根本原因: 使っていない部品が2つ入っていた

`browser-sync` と `concurrently` を調べたところ、**どのスクリプトからも呼ばれていませんでした。**

```
"dev":   "node server/bridge.js --open"
"start": "node server/bridge.js"
```

`bs-config.cjs` も置いてありましたが、**それを読む起動が存在しません。**
README にも「browser-sync が3005番で動く」と書いてありましたが、**そうなっていませんでした。**
古い構成の名残です。

**警告4件のうち2件は、使っていないものが持ち込んでいた**ことになります。

## 解決策

| やったこと | 効いたもの |
|---|---|
| `browser-sync` を依存から外す | `immutable` |
| `concurrently` を依存から外す | `shell-quote` |
| `bs-config.cjs` を削除 | — |
| `npm prune` | 上記の実体を撤去 |
| `npm audit fix`（**`--force` なし**） | `fast-uri` / `hono` / `brace-expansion` |

**`npm audit fix --force` は使っていません。** あれは `browser-sync` を
3.x から **1.9.2 へ下げる**提案で、10年以上前の版になります。
使っていないものを直すために大きく壊すのは筋が悪い。**外すほうが正しい。**

## 検証結果

| 調べたこと | 結果 |
|---|---|
| `npm audit` | **0件**（1件も残っていない） |
| `npm start` で立ち上がるか | **立ち上がる**（`http://localhost:3000`） |
| `/api/ai-status` | **`agentSdk: true, primary: "claude"`** |
| アプリが配られるか | **200** |
| **札が緑になるか** | **🟢 このPCの Claude**（設定・チャット両方） |
| **実際に生成できるか** | **できた**（`provider=claude (Agent SDK)`） |

**外したことで壊れたものはありません。** 使っていなかったので当然ですが、
確かめずに「使っていないはず」で済ませない。

## あわせて直したもの

README の「browser-sync が3005番で動く」という記述を消し、
**実際の立ち上がり方**（`bridge.js` がアプリごと配る／`localhost:3000` を開く）に直しました。
札の色の見かたも書き添えています。

## 申し送り

- **`npm audit` の件数だけを見ない。** 「どこに配られるものか」「誰が触れるか」で
  重さがまったく変わる。今回は**配られるものには1件も無かった**
- **`--force` の提案は、内容を読むこと。** 版を大きく下げる提案が混ざる
- 依存を足したら、**使わなくなったときに外す**。使っていないものは、
  黙って持ち込みだけ増やす
