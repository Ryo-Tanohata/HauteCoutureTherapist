# ISSUE-082: カルテのカードが、書く手立ての無い項目まで「未記入」と出していた

## 概要
- **発生日**: 2026-08-21
- **分類**: 不具合（表示と入力の食い違い）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状

> なんでカラーセラピーを選んでいないのに選んだ色を表示する場所があるんだろう

🦄counseling だけを選んだ記録のカードに、「**選んだ色: 未記入**」が出ていました。

色を選ぶ欄は、🌈color を選んだときだけカラーセラピーのカルテの中に開きます。
選んでいなければ**欄そのものが出ません**。つまり、書く手立てが無いのに
「書き忘れ」に見える状態でした。

同じことが 🧪処方でも起きていました。処方の欄は ISSUE-080 で画面から下ろしたので、
手では書けません。それなのに「処方: 未記入」が必ず出ていました。

## 原因

**入力側だけが直り、表示側が取り残されていた。**

`buildRecordDetailsHtml()` は、4行（選んだ色・訴え・処方・メモ）を
**中身の有無にかかわらず必ず出す**作りでした。

これは ISSUE-019 でわざとそうしたものです。当時は「値があるときだけ出す」形で、
旧バージョンの記録（マイグレーションで空文字が入る）では行ごと消え、
**項目そのものが無いように見えた**ためでした。

その前提は、もう成り立ちません。ISSUE-080 でカルテが区分ごとに分かれ、
書く欄は**選んだ区分のぶんだけ開く**ようになったからです。
「欄が見えない」ことが、いまは「この記録には関係ない」を意味します。

なお、区分ごとのカルテ（`buildKarteDetailsHtml()`）は前から
「中身があるときだけ出す」作りでした。**4行だけが取り残されていました。**

## 直したこと

カードの4行を「**書いたものだけ出す**」に変えました（`product/js/app/ui.js`）。

- 中身の無い行は、行ごと出しません
- 書いてある行は、これまでどおり出ます
- 4項目とも空でも、カードの中は空になりません（✏️変更 / 🗑️削除 が残ります）

**区分ではなく、中身で決めています。** 見本の記録のように、区分の仕組みより前に
作られて「🌈は付いていないが色は入っている」記録があります。
区分で判断すると、こうした記録の色が**画面から消えてしまいます**。

## 検証結果

`management/09_Verification/verify-card-rows.js`

| 見たこと | 結果 |
|---|---|
| 空の行が1つも出ていない | ✅ |
| 書いてある行はちゃんと出る（消しすぎていない） | ✅ |
| 4項目とも空でも、カードの中に押せるものが残る | ✅ |
| 記録の中身と、行の出方が合っている（4枚を突き合わせ） | ✅ |

あわせて `verify-accordion` / `verify-categories` / `verify-demos` も通ることを確認しました。

## 気づいたこと

- **見本の記録は4項目とも埋まっていた。** そのままだと「空なら出ない」ほうを
  **一度も試さずに通ってしまう**。空の記録を意図的に入れて確かめるようにした。
  最初の版は 0件を突き合わせて ✅ を出していた
- **区分と中身は別もの。** 「🌈が付いていない＝色が無い」ではない
- 頭の帯の時刻は `14:00 - 15:00` のように**空白を含む**。`\S+` では取りこぼす

## 申し送り

**「下ごしらえ」が、見えない欄に書いています。** 処方の欄を ISSUE-080 で下ろしたため、
ボタンを押すと「✓ 処方・メモに入れました。内容を確認して、必要なら書き直してください」
と出るのに、**処方は画面に無いので確認も書き直しもできません**。

サロンからは「現在のところ下ごしらえは不要。ただし復活するかもしれない」とのご判断で、
**下ろし方（消す／残す）を相談中**です。
