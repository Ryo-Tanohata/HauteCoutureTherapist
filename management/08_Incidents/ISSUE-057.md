# ISSUE-057: 端末のメニューが消えない／アーカイブだけ見た目が浮いている

## 概要
- **発生日**: 2026-08-08
- **分類**: MINOR（v1.38.0）
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

### ① 直したはずのメニューが、まだ出る

> また 取り扱い説明書のところだけ ブラウザ 画面が出てしまいます
> これが出ないようにしてください

ISSUE-056 で止めたはずのものが、**実機ではまだ出ていました。**

### ② アーカイブだけ、見た目が浮いている

> アーカイブ 他のところだけ 薄く 色がかってるのが自然なので周りに合わせてください

## ①の根本原因: 止める指定では、足りなかった

ISSUE-056 では「`contextmenu` を止める」「`-webkit-touch-callout: none` を当てる」で対処しました。
検証（Chromium）では**きちんと止まっていました。**

しかし実機は、**アプリ内ブラウザ**（画面上部に ✕ と ⋮ が出ている、Chrome の簡易ブラウザ）でした。
そこでは**止める指定が効きません。**

**「効くはずの指定を入れた」で終わらせたのが誤りでした。**
サロンが使っている開き方で確かめていません。

### 直しかた: そもそもリンクをやめる

止める指定を重ねるのではなく、**リンクであること自体をやめました。**

```html
<!-- 前 -->
<a id="btn-view-manual" href="manual.html" target="_blank">📖 取扱説明書</a>

<!-- 後 -->
<button id="btn-view-manual" type="button">📖 取扱説明書</button>
```

開くのはこちらでやります。

```js
btnViewManual.addEventListener('click', () => {
    window.open('manual.html', '_blank', 'noopener');
});
```

**リンクが無ければ、端末に出すものがありません。** 指定の効き目に頼らずに済みます。

ISSUE-056 で入れた守り（`a[href]` を対象に含める・`data-lp-held` の印）は、
**そのまま残してあります。** 今後うっかりリンクを置いても、
効く環境では止まります。**重ねておくほうが安全です。**

## ②の根本原因: そこだけ枠と塗りが付いていた

並んでいる4つのうち、**アーカイブだけ**が枠と背景を持っていました。

```js
btnDetailArchive.style.background = 'rgba(245, 158, 11, 0.15)';
btnDetailArchive.style.border = '1px solid #f59e0b';
```

| | 背景 | 枠 | 文字色 |
|---|---|---|---|
| ✏️ 編集 | 無し | 無し | 既定 |
| **📦 アーカイブ** | **あり** | **あり** | 橙 |
| 🗑️ 削除 | 無し | 無し | 赤 |
| ✕ 閉じる | 無し | 無し | 既定 |

**削除のほうが取り返しがつかない**のに、そちらは文字の色だけです。
**押す前から目立たせる理由がありません。**

背景と枠を外し、**文字の色だけ**にしました。解除できる状態のときは緑にして、
戻せることは色で伝えます。

## 検証結果

`verify-nomenu.js`（390px・タッチあり）

| 調べたこと | 結果 |
|---|---|
| **入口がリンクではなくボタンか** | **ボタン** |
| メニューが出ないか | **出ない** |
| 説明を出している最中も出ないか | **出ない** |
| ほかの7つのアイコン | **すべて出ない** |
| 入力欄・記録の本文 | **これまでどおり写せる** |
| **押すと説明書が別の窓で開くか** | **開く**（`manual.html` / `_blank`） |
| 説明そのもの | **出る** |

アーカイブの見た目（`btn-detail-archive`）

```
前: background: rgba(245,158,11,0.15); border: 1px solid #f59e0b
後: background: transparent; border: none; color: #f59e0b
```

**削除（赤）と同じ形**になりました。

既存のもの（`verify-csp.js` / `verify-tooltip-linger.js` / `verify-ai-route.js` /
`verify-manual.js`）も通っています。

## 申し送り

- **「指定を入れた」で終わらせない。** アプリ内ブラウザでは効かないものがあります。
  **止める指定より、止めるものを無くすほうが確実です**
- 検証は Chromium で行っています。**アプリ内ブラウザは再現できません。**
  実機で見ていただくまで、確からしさは一段落ちる、と扱うべきでした
