# ISSUE-053: 札に「このPCの Claude」と出ているのに、チャットはAPIキーで答えていた

## 概要
- **発生日**: 2026-08-07
- **分類**: MAJOR（v1.35.0）／**表示が事実と違っていた**
- **状態**: **対応済み**
- **担当**: Claude Code

## 症状 / 要望

> ローカルでの挙動も確認できましたが、「このPCのClaude」ではなく
> ClaudeのOpus5などのモデル名が分かるようにしたいです。apiかどうかもそうです

送っていただいた画面を見て、**別の問題に気づきました。**

ヘッダーには **🟢「このPCの Claude」** と出ているのに、
**チャットはAPIキー（Gemini）で答えていました。**

## 根本原因: 札は「アプリの繋ぎ先」を見ていて、チャットは別の道を通っていた

ISSUE-051 で入れた札は、`/api/ai-status` を見て
「**星詠み・下ごしらえがどこへ行くか**」を出していました。

ところがチャットは、ISSUE-050 でキーの入れ物を寄せたとき、
**`generateWithOwnKey()`（＝ブラウザから直接キーで）だけを通る**ようになっていました。
PCのサーバーに頼む道を、そもそも持っていませんでした。

`bridge.js` の `/api/chat` は、中身が

```js
res.json({ message: "Bridge connection successful" });
```

**つながるか試すだけの、空の入口**でした。

**札は正しく、チャットが札の言うとおりに動いていなかった。**
これは「表示が事実と違う」という、いちばん質の悪い形です。
サロンは画面を信じるしかないためです。

### どうして気づけなかったか

ISSUE-051 の検証は、**札が出るか**しか見ていませんでした。
**札の言うとおりに動いているか**は見ていません。

サロンから送られた画面（緑の札と、Gemini のキーが5本入っている一覧が同時に写っている）で
初めて気づきました。**検証の穴です。**

## 直したこと

### 1. `/api/chat` を本物にした

`generateAdvice()`（Agent SDK → Anthropic → Gemini の順に試す仕組み）を呼び、
使ったものを返します。**星詠みが既にやっている形と同じ**にしました。

### 2. チャットも、まずPCのサーバーに頼むようにした

```
PCのサーバーに聞く → 居れば、それで答える（アカウント／キー不要）
              └ 居なければ、登録したキーで答える
```

**これで札と中身が一致します。**

### 3. モデル名と、支払い方が分かるようにした

| 前 | 後 |
|---|---|
| `このPCの Claude` | `アカウント · claude-haiku-4-5` |
| `登録したAPIキー（Google（Gemini））` | `APIキー · gemini-2.5-flash` |

- **`アカウント`** … 契約の枠で動く。**従量の課金は発生しません**
- **`APIキー`** … 使った分だけ課金されます

`/api/ai-status` に `models` と `plannedModel` を足し、**呼ぶ前から**分かるようにしました。
さらに、**返事を作ったあとは実際に使われた名前へ更新**します（版まで含んだ正確な名前）。

```
呼ぶ前 : アカウント · claude-haiku-4-5
答えた後: アカウント · claude-haiku-4-5-20251001
```

見込みと実際は食い違うことがあります（1本目のキーが上限に当たって2本目に移った、など）。
**動いた結果のほうが正しい**ので、そちらで上書きします。

## サロンへの申し送り: いま使われているのは Opus ではありません

札を出したことで分かったことです。

```json
"models": { "claude": "claude-haiku-4-5", ... }
```

**このPCで動いているのは claude-haiku-4-5 です。** いちばん軽く速いものです。

変えるなら、立ち上げるときに指定できます。

```bash
CLAUDE_MODEL=claude-opus-5 npm run dev
```

**ただし、重いモデルほど時間がかかり、契約の枠も早く減ります。**
「下ごしらえ」は400字ほどの業務メモなので、いまのままで足りている可能性が高いです。
**変えるかどうかは、実際に見比べてから決めるのが確実です。**
