# ISSUE-026: 端末をまたいでカルテを引き継ぐ「サロンの置き場」の新設と、Cloudflare Pages への移設

## 概要
- **発生日**: 2026-08-05
- **分類**: MINOR (v1.17.0)
- **担当**: Claude Code

## 症状 / 要望
カルテが端末の `localStorage` にしか無く、パソコンで書いたものがスマホで見られなかった。

当初は OneDrive とパソコンのフォルダ同期で解決を図ったが、どちらも成立しなかった。

1. **OneDrive**: Microsoft Entra のアプリ登録が必要。サロンのアカウントで開こうとしても必ず別アカウントの入力を求められ、登録そのものができなかった。
2. **フォルダ同期**: File System Access API がスマホの Safari / Chrome に無く、iPhone で使えなかった。

「サロン側でアカウントを作る・アプリを登録する」という前提そのものを外す必要があった。

あわせて、配信先だった Vercel の Hobby プランは規約で個人・非商用の利用に限られ、「理由の有無にかかわらず予告なく停止できる」と明記されている。営業中のサロンのカルテを置いたままにできないため、無料プランでも商用利用が認められている Cloudflare Pages へ移すことにした。

## 根本原因
アカウント連携を前提とした同期方式（OneDrive / Google Drive / File System Access API）は、いずれもサロン側に管理者権限のある組織アカウントか、デスクトップブラウザを要求する。スマホ主体で、かつ IT 管理者のいないサロンでは、この前提が満たせない。

## 解決策

### 1. 合言葉ひとつで済む「サロンの置き場」
サインインもアプリ登録も無くし、**合言葉を1回入れるだけ**でつながる方式にした。iPhone でも動く。

### 2. 置き場からは中身が読めない設計
カルテには体質・アレルギー・施術記録が入る。漏れたときに取り返しがつかないため、**預ける側で読めなくしてから預ける**。

- 合言葉から PBKDF2（SHA-256・210,000回）で512ビットを作り、前半後半を別用途に使う
  - 前半（バイト 0〜32）… AES-GCM の暗号化鍵。**この端末から出ない**
  - 後半（バイト 32〜64）… 合言葉が合っているかを見てもらうための値。**これだけを送る**
- PBKDF2 は前半（T_1）と後半（T_2）を独立に計算するため、後半を握っても前半は割り出せない。サーバーを預かる側にも中身は読めない
- 暗号文は `iv(12バイト) || 本体` の形で置く

### 3. 塩を固定値にした
当初は塩に `location.origin` を混ぜていたが、これだと同じ合言葉でも開く場所によって別の鍵になる。

- 独自ドメインを付けた
- www あり／なしで開いた
- プレビュー用のURLで設定して、本番で使った

いずれも「昨日まで開けたのに、今日は合言葉が違うと言われる」になる。データが入る前に、固定文字列 `HauteCoutureTherapist|salon-store|v1` へ変更した。

### 4. Cloudflare Pages Functions + R2
`functions/api/sync.js` を Pages Function として置き、R2 バケットを `SALON_STORE` として結び付けた。

- `salon/data.bin` … カルテ本体（暗号化済み）
- `salon/photos/<id>.bin` … 写真（暗号化済み）
- 合言葉の照合は `crypto.subtle.timingSafeEqual` で行い、比較時間から情報が漏れないようにした
- 写真IDは `/^[A-Za-z0-9_-]{1,64}$/` で検証し、キーの外へ出られないようにした
- `Cache-Control: no-store` を付け、更新が古い内容で上書きされないようにした

### 5. 変更のたびに送る
当初は「開いたとき」と「手で押したとき」しか同期していなかったため、パソコンでの変更がスマホに出るまで気付けなかった。`saveCustomers` に `onDataChanged` を挿し、書き換えのたびに送るようにした。ヘッダーに同期状態のバッジも出す。

突き合わせは記録ごとの `updatedAtISO` を見て**新しいほうを残す**。

## 変更ファイル
- `product/js/app/salon-store.js`（新規。合言葉・鍵づくり・暗号化・同期）
- `functions/api/sync.js`（新規。Cloudflare Pages Function と R2）
- `product/_routes.json`（`/api/*` を Function へ回す）
- `product/js/app/data.js`（`onDataChanged` フック）
- `product/js/app/ui.js`（設定画面・同期の起点・同期バッジ）
- `product/css/index.css`（同期バッジ）
- `product/js/app/cloud-sync.js` / `folder-sync.js`（削除。OneDrive・フォルダ同期）

## 残っている限界（承知のうえ）
- **合言葉を忘れると、置いてあるものは誰にも読めない。** 取り戻す道は無い
- **合言葉はこの端末に控える。** 端末そのものを他人に渡せば、その人は中身を見られる。守っているのは「置き場に預けたぶん」であって、端末の中ではない
- **消したことは伝わらない。** 突き合わせは「新しいほうを残す」ため、片方で消した記録はもう片方から戻ってくる
