# 色と星の対応表（v1.0）

顧客のソウルカラーから「担当する天体」と「チャクラ（施術部位）」を引くための表。
アプリの実装は `product/js/app/correspondence.js` が正本で、この文書はその読み下し。

**確定済みの前提**

| 項目 | 決定 |
|---|---|
| 禁忌との優先順位 | **禁忌・既往歴が常に優先。** 星の対応が精油を示しても、注意事項に抵触するなら採用しない |
| クライアントへの開示 | **しない。** セラピスト側の参考情報にとどめる |
| 流派 | 資料が割れる箇所はこちらで決めた（下の「決めた理由」参照）。和泉さんのレビューで変更する |

## 1. 設計

### 2本の対応を独立に持つ

```
                   ┌─ 天体 → 今その天体がどのサインにいるか（星詠みが計算）
   ソウルカラー ────┤        → その天体系の精油
                   └─ チャクラ → 施術部位
```

この2本は**起源の違う体系なので、互いに整合していなくてよい**。
例：青は天体では月だが、チャクラでは第5（喉）。チャクラ側の伝統的な天体対応では第5は水星。
無理に揃えるとどちらかが壊れるため、あえて分けている。

### 身体部位はチャクラから引く（星座からではない）

当初は 色 → 星座 → 身体部位（医療占星術のメロテジア）を想定していたが、チャクラに変更した。

- チャクラは**色が直接定義されている**（赤=第1、緑=第4…）ので、色→星座の変換で発生していた不確かさが消える
- **アロマトリートメントの施術部位そのもの**なので実務に直結する
- TCカラーセラピーのキーワードと一致する（ダーク=「グラウンディング」=第1、ゴールド=「自信・自己価値」=第3）

### 数秘の番号は経由しない

ソウルカラーのキーは `1-red` `7-purple` のように数秘の番号を持つが、
**「番号→天体→色」で辿ると12色中6番しか色が合わない。**

| 番号 | アプリの色 | カルデアン数秘の天体 | その天体の伝統色 | 一致 |
|---|---|---|---|---|
| 1 | 赤 | 太陽 | 金・橙 | ✗（赤は火星） |
| 3 | 黄 | 木星 | 紫 | ✗ |
| 4 | 緑 | 天王星 | ターコイズ | ✗ |
| 5 | ターコイズ | 水星 | 黄・水色 | ✗ |
| 6 | ピンク | 金星 | ピンク | ✓ |
| 8 | オレンジ | 土星 | 黒・灰 | ✗ |

数秘の色体系と天体の色体系は起源が別物。番号を捨て、**色相そのもの**で対応させる。

### 3つのカラー体系を1枚に集約

顧客のソウルカラーはソウル12色／TC14色／アドバンス17色の**どれからでも選べる**（1顧客につき1体系にロック）。
体系ごとに表を作ると3重管理になるので、**色相20種の表を1枚だけ持ち、43キー全部をそこに寄せている。**

### 近代天体の精油について

天王星・海王星・冥王星は近代に発見されたため、**伝統的な精油の割当が存在しない**。
占星術で標準的な「高次オクターブ」の考え方（天王星=水星の高次、海王星=金星の高次、冥王星=火星の高次）に沿って、実務で定番の精油を借用している。画面上でもその旨を明示している。

## 3. 実装

| ファイル | 役割 |
|---|---|
| `product/js/app/correspondence.js` | 対応表の正本。**直すのはここ1箇所** |
| `product/js/app/ui.js` の `renderColorStarTab()` | 顧客詳細の「✨星」タブの描画 |
| `server/advice.js` の `buildPlanetaryData()` | 10天体の位置を計算して星詠みのファイルに書く |
| `scripts/refresh-advice.js --backfill` | AIを呼ばずに天体データだけ再計算する |

### 表の直し方

`COLOR_CORRESPONDENCE` の該当する色相の**1行だけ**を書き換える。
3体系のキーはすべて `keys` でその色相に紐づいているので、1行直せば全体に効く。

```js
{
    hue: 'インディゴ（藍）',
    keys: ['11-indigo', 'tc-indigo', 'adv-indigo'],
    planet: 'neptune',   // ← ここを 'saturn' に変えれば土星になる
    chakra: 6,
    confidence: 'low',
    note: '…'
},
```

### 天体の追加について

星詠みは元々 太陽・月・水星・金星・火星の5天体しか計算していなかった。
紫（木星）・オリーブ／茶／黒（土星）・ターコイズ（天王星）・インディゴ（海王星）・マゼンタ（冥王星）を
引けるようにするため、**木星・土星・天王星・海王星・冥王星の5つを追加**した。

既存の保存済み星詠み6本には `--backfill` で天体データだけを追記した（**文章は再生成していない**。
生成時と同じ日時で計算しているので、文章と天体の位置がずれることはない）。
