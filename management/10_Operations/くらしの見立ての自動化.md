# くらしの見立て：自動で書く仕組みの設定

「見立てを頼む」を押すと、Lou さんの claude.ai アカウントのルーティンが起動し、
見立てを書いて画面へ届けます。サブスクの枠で動くので、従量課金はありません
（使用量クレジットをオンにしていない限り）。

```
画面「見立てを頼む」 → /api/mitate（入口の内側） → ルーティンの API トリガー
                                                    ↓
画面が8秒ごとに見に行く ← R2（mitate/req/<id>） ← /api/mitate-result（合鍵つき）
```

- ルーティン：`くらしの見立て（サロン画面から起動）`（trig_016gTB3rYx8R2tGhpLemQBvR）
- 指示書：`scripts/mitate/ROUTINE.md`（決まりを直すときはここを直す）
- 窓口：`functions/api/mitate.js`（起動・待ち）、`functions/api/mitate-result.js`（受け取り）

## 設定（画面で1回だけ）

合鍵 `MITATE_RESULT_KEY` の値は、チャットで別にお伝えしたものを使います（ここには書かない）。

### 1. ルーティンを整える（claude.ai/code/routines）

1. 「くらしの見立て（サロン画面から起動）」を開き、名前の横のメニュー →「Edit」
2. **Connectors**：Gmail・Google Drive・Google Calendar などは外す（このルーティンには要らない）
3. **環境**：Instructions の下の雲のアイコン → 環境の設定（歯車）
   - Network access を **Custom** にし、Allowed domains に `hautecouturetherapist-98c.pages.dev` を足す。「Also include default list…」にもチェック
   - 環境変数に `MITATE_RESULT_KEY=<合鍵の値>` を足す
4. **Select a trigger** →「Add another trigger」→ **API** → 保存
5. 出てきた URL を控え、「Generate token」で合鍵を出して控える（一度しか表示されない）

### 2. Cloudflare Pages に入れる（Workers & Pages → hautecouturetherapist → 設定 → 変数とシークレット）

| 名前 | 種類 | 値 |
|---|---|---|
| `MITATE_ROUTINE_URL` | テキスト | 1-5 の URL（…/routines/trig_…/fire） |
| `MITATE_ROUTINE_TOKEN` | シークレット | 1-5 の合鍵 |
| `MITATE_RESULT_KEY` | シークレット | 1-3 と同じ合鍵の値 |

入れたら、デプロイをやり直す（最新のデプロイ →「再試行」）。

### 3. 入口の例外を1本だけ作る（Zero Trust → Access → Applications）

ルーティンはクラウドで動くので、メールの数字の入口を通れません。受け取り口だけを例外にします。

1. 「Add an application」→ **Self-hosted**
2. ドメイン：`hautecouturetherapist-98c.pages.dev`、パス：`api/mitate-result`
3. ポリシー：Action を **Bypass**、Include を **Everyone**
4. 保存（パスつきのほうが優先される。ほかの場所は今までどおり入口が効く）

受け取り口は `MITATE_RESULT_KEY` を持たない呼び出しを断り、こちらが待っている依頼の答えしか受け取りません。

## 動かしてみる

1. `/mitate/` で聞き取って、「3 見立てる」→「見立てを頼む」
2. 「ただいま、星を読んでいます…」が出て、数分で見立てが届けば成功
3. 届かないとき：claude.ai/code/routines のルーティンの実行一覧で、その回を開いて理由を見る
   - 窓口へ 403 → 3 の例外か、1-3 のネットワーク許可
   - 窓口へ 401 → `MITATE_RESULT_KEY` が2か所で違う
   - 画面に「Claude を起動できませんでした（401）」→ `MITATE_ROUTINE_TOKEN` か URL

## 上限

- 画面からは1時間に20回まで（こちらで絞っている）。ルーティン側の上限は1時間に30回
- 20分たっても届かなければ、画面は「届きませんでした」と出して待つのをやめる
- 届いた見立ては、画面が受け取った時点で置き場から消す。受け取られないものは1日で消す
