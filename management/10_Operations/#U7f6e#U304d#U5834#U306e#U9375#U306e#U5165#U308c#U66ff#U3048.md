## 1. いま、どうなっているか

合言葉ひとつから、**2つの値**を作っています。

```
  合言葉（12文字以上）
        │
        └─ PBKDF2（21万回・塩は固定）→ 512ビット
                                        ├─ 前半256ビット … 暗号化の鍵（端末から出ない）
                                        └─ 後半256ビット … 置き場の合言葉（SALON_KEY）
```

後半だけが Cloudflare に登録され、通信のたびに送られます。前半は一切外へ出ません。

**「後半から前半は割り出せない」——これは正しいです。** PBKDF2 は前半と後半を
別々に計算するので、片方から他方を計算することはできません。

## 2. それでも困ること

### ⓐ 後半を見た人は、合言葉そのものを探せる

割り出すのではなく、**総当たりで当てにいけます。**

塩は決め打ちで、コードに書いてあります（秘密ではありません）。
繰り返しは21万回。手元の機械で、合言葉の候補を片端から同じ計算にかけて、
出てきた後半が一致するかを見るだけです。

**当たれば、前半＝暗号化の鍵も作れます。** 置いてあるカルテは読めます。

これが効くのは、`SALON_KEY` を見られる立場の人です。

- Cloudflare の管理画面に入れる人
- その画面を写した画像が、どこかに残っていた場合
- Cloudflare 側の記録が漏れた場合

合言葉が長くて、辞書に無い並びなら、現実には届きません。
**短かったり、思いつきやすい言葉だと届きます。**

> 設定画面には「こちらから合言葉を割り出すことはできません」と書いてあります。
> **割り出せない**のは本当ですが、**総当たりで当てられる**ことに触れていません。
> ここも直します。

### ⓑ 合言葉を、中身を失わずに変えられない

合言葉を変えると、前半＝暗号化の鍵も一緒に変わります。
**いま置いてあるものは、新しい合言葉では開きません。**

つまり「漏れたかもしれないので変えたい」ができません。
いちばん変えたいときに、いちばん変えにくい形になっています。

---

## 3. 直したあと、どうなるか

**2つの秘密を、別々のものにします。**

```
  合言葉（12文字以上）──→ PBKDF2 ──→ 暗号化の鍵（端末から出ない）

  置き場の合言葉 ──────→ そのまま送る（乱数。合言葉とは無関係）
```

| | いま | 直したあと |
|---|---|---|
| 置き場の合言葉を見られたら | **合言葉を総当たりできる** | ただの乱数。合言葉の手がかりにならない |
| 置き場の合言葉を変えたい | 中身が開けなくなる | **中身はそのまま。入れ替えるだけ** |
| 合言葉を変えたい | 中身が開けなくなる | 中身を書き直す必要はあるが、置き場の側は触らない |

### 正直に言っておくこと

**これで「絶対に読まれない」にはなりません。**

置き場の合言葉を手に入れた人は、**暗号化されたかたまりを取ってこられます**。
そのかたまりを相手に、合言葉を総当たりすることは、やはりできます。

変わるのは、こういうところです。

- **置き場の合言葉だけでは、何も分かりません。** 取ってくるという一歩が要ります
- **その一歩は、鍵を入れ替えれば断てます**（いまは断てません）
- 管理画面を見ただけの人と、実際にデータを取った人が、**別のものになります**

## 4. 手順

### 大事なこと：**止まる時間を作らない**

置き場は「この合言葉で来た人だけ通す」という作りです。
**新しいものに切り替えた瞬間、まだ切り替えていない端末は締め出されます。**

スマホが3台あって、1台ずつ入れ直すなら、その間ずっと同期が止まります。

そこで、**しばらくのあいだ、古いものと新しいものの両方を通す**ようにします。
（`SALON_KEY` と `SALON_KEY_NEXT` の2つを見る形にします）

こうすれば、端末を1台ずつ、都合のよいときに入れ替えられます。

### 段取り

| | すること | 誰が | 止まるか | 戻せるか |
|---|---|---|---|---|
| **0** | 全部の端末で同期し、**1台で 📤 書き出し**をしておく | サロン | — | これが最後の砦 |
| **1** | 両方を通せるようにしたものを配信 | 私 | 止まらない | すぐ戻せる |
| **2** | Cloudflare に `SALON_KEY_NEXT` を足す（新しい乱数） | サロン | 止まらない | 消せば元どおり |
| **3** | 端末を1台ずつ、新しいものに入れ替える | サロン | 止まらない | 古いのに戻せる |
| **4** | 全部済んだら、Cloudflare の `SALON_KEY` を消す | サロン | 止まらない | — |

**3 が済むまで、どの端末も動き続けます。** 急ぐ必要はありません。

### 0 の書き出しについて

**書き出したファイルは暗号化されていません。** 手順が終わるまでの間だけ持って、
終わったら消してください。置き場所は、パソコンの中よりも
**USBメモリなど、ネットに繋がらないところ**が確かです。

（先日お伝えしたとおり、プロジェクトのフォルダには置かないでください）

## 5. 決めていただきたいこと

### ① いま、やりますか

**急ぎではありません。** `SALON_KEY` が漏れた心当たりが無いなら、
いつやっても構いません。ただし「漏れたかもしれない」と思ったときには、
**いまの形では手の打ちようがありません**。そこだけが理由です。

### ② 合言葉そのものも、変えますか

**変えなくてよいと思います。**

いま直そうとしているのは「置き場の合言葉」のほうです。
合言葉そのものは、端末の中と、サロンの頭の中にしかありません。
漏れた心当たりが無ければ、そのままで構いません。

変える場合は、**置いてあるものを書き直す**作業が別に要ります。
その間、書き直していない端末は同期できません（手元の記録は消えません）。

### ③ 塩と繰り返しの回数も、直しますか

**以前「変えないでください」と伺っています。** 変えると、いま置いてあるものが
開けなくなるためでした。

ただし②で書き直すなら、**そのついでに直せます**（追加の手間はほぼありません）。

| | いま | 直すなら |
|---|---|---|
| 塩 | 決め打ち・全員同じ | 端末ごとに乱数。あらかじめ作った表が効かなくなる |
| 繰り返し | 21万回 | 60万回（いまの推奨） |

②をやらないなら、③もやりません。**セットです。**

---

## 6. やらない、という選択

やらない場合、こうなります。

- **置き場の合言葉が漏れても、打つ手がありません。** 変えれば中身が読めなくなります
- 唯一できるのは「置き場を作り直して、書き出したファイルから入れ直す」ことです
  （できます。ただし**全部の端末で入れ直し**になります）

つまり「やらない」でも詰みはしませんが、**困ったときの手間が大きく違います。**
