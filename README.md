# セラピスト向け顧客管理アプリ (Therapist CRM)

セラピストがスマートフォン上で顧客情報、来店履歴、施術内容、お支払金額をスムーズに確認・記録できる、スマホ最適化の顧客管理システムです。

## 1. 特徴・機能
- **スマホ特化UI**: 4つの情報を瞬時に切り替えるタブコントロールを配置。
- **LocalStorage 連携**: データベース不要で、ブラウザ内で完結する安全なデータ永続化。
- **検索フィルタ**: 顧客名やよみがなによるインクリメンタルなあいまい検索。
- **自動ログ分類・保存**: 開発時のAI対話ログをアクセス元URLごとに自動で階層分類して保存するデベロッパーブリッジを搭載。

## 3. 星詠みメッセージ（生成と共有）
星詠みメッセージは**あらかじめ生成してファイルに保存**し、ブラウザはそのファイルを読むだけです。

```
定期実行 ── Claude ──▶ product/data/advice/<period>.json ──▶ ブラウザが読む
（あなたのPC・あなたのプラン）        （リポジトリに保存）      （AIは呼ばれない）
```

閲覧者が何回開いても、タブを何回切り替えてもAIは呼ばれません。生成が走るのは定期実行のときだけです。

### 生成（定期実行）
```bash
claude                       # 一度ログインしておく（以降この認証が使われる）
npm run advice:refresh       # 更新サイクルが来た期間だけ生成
npm run advice:status        # 各期間の最終生成日時と更新要否を確認
npm run advice:refresh:all   # 全期間を強制的に再生成
```

期間ごとの更新サイクル（today は毎日、1week は毎週、1year は毎年…）を過ぎたものだけが生成対象になります。サイクル内の期間はスキップされるので、**毎日1回実行しておけば全期間が適切な頻度で更新されます**。

> ⚠️ **`advice:refresh` は「作る」だけです。** 生成したJSONはリポジトリのファイルなので、
> **コミットして push するまで、他の端末の画面は変わりません。**
> 「毎日実行する」と「毎日配る」は別の話で、両方が必要です（ISSUE-059）。

### 毎日の更新を自動にする
「生成 → コミット → push」を1本にまとめたものを用意してあります。

```powershell
# Windows（タスクスケジューラから毎日呼ぶ）
powershell -ExecutionPolicy Bypass -File scripts\daily-advice.ps1 -DryRun   # 確認だけ
powershell -ExecutionPolicy Bypass -File scripts\daily-advice.ps1           # 本番
```
```bash
# Mac / Linux（cron から毎日呼ぶ）
npm run advice:daily:check   # 確認だけ
npm run advice:daily         # 本番
```

`main` 以外のブランチにいる場合は**何もせずに停止**し、コミット対象は
`product/data/advice` 配下だけに限定してあります。実行結果は `logs/daily-advice.log` に残ります。

登録手順（タスクスケジューラ／cron）: `management/10_Operations/星詠みの毎日更新.md`

画面側には、更新サイクルを過ぎているかどうかが `✅ 最新です` / `⚠️ 更新サイクルを N日 過ぎています`
として表示されます。PCが停止していて更新が飛んだ日は、これで気付けます。

### 生成AI（Claude 優先・Gemini フォールバック）
Claude を優先し、失敗した場合のみ Gemini にフォールバックします。実際にどちらが使われたかは、星詠みビューのバッジに「🤖 生成AI: ...」として表示されます。

Claude の認証は **このPCの Claude ログイン**（Claude Agent SDK 経由）を使います。APIキーの発行は不要で、生成はあなたのプラン枠で行われます。アプリ側にログイン画面は出ません。

### 環境変数
| 変数 | 既定値 | 用途 |
|---|---|---|
| `AI_PROVIDER` | （未設定） | 使うAIを1つに固定する（`claude` / `anthropic` / `gemini`）。指定するとフォールバックしない |
| `CLAUDE_MODEL` | `claude-haiku-4-5` | Claude のモデル。既定は `product/js/app/model-registry.js` の先頭（速さ優先）。星詠みのような長い読み物には `claude-sonnet-5` を明示すること（`daily-advice` は指定済み） |
| `CLAUDE_TIMEOUT_MS` | `180000` | Agent SDK の応答待ちタイムアウト |
| `GEMINI_API_KEY` | （未設定） | フォールバック先。カンマ区切りで複数指定可 |
| `ANTHROPIC_API_KEY` | （未設定） | `AI_PROVIDER=anthropic` の時に使うAPIキー |

### 共有について
**この構成なら共有できます。** 閲覧者はAIに触れず、生成済みのテキストファイルを読むだけだからです。生成はあなたが自分のPCで自分のプラン枠で行い、その成果物を配る形になります。

守るべき境界は1つだけです。

> **閲覧者の操作が生成のきっかけになってはいけません。**

- ✅ 定期実行で生成 → ファイルを配る（現在の構成）
- ❌ 「再生成」ボタンを付けて閲覧者に押させる
- ❌ 顧客ごとの星詠みを、閲覧者の操作で都度生成する

後者に踏み込む場合は `ANTHROPIC_API_KEY` が必要になります（[Agent SDK overview](https://code.claude.com/docs/en/agent-sdk/overview) の記載: 事前承認がない限り、claude.ai のログインやレート枠を自分のプロダクトに使うことは認められていません）。

なお保存されるJSONに**顧客の個人情報は一切含まれません**（天体データと生成文のみ）。顧客データは従来どおり各ブラウザの localStorage に留まり、ファイルにも共有先にも出ていきません。

## 4. 端末をまたいでデータを引き継ぐ

顧客データは各ブラウザの中にあるため、そのままでは端末を変えると引き継げません。受け渡しの道は2通りで、設定画面（⚙️ 設定）にあります。

| | サロン側の手間 | iPhone |
|---|---|---|
| 🔑 **サロンの置き場** | 合言葉を1回入れるだけ | ✅ |
| 💾 **書き出し・読み込み** | ファイルを手で受け渡す | ✅ |

以前は OneDrive とパソコンのフォルダへ同期する道も用意していましたが、どちらもサロン側の登録作業が要るうえに使われず、設定画面を塞いでいたため外しました。

### どこに push すると配信されるか

**Cloudflare Pages が見ているのは GitLab の `main` だけです。**（Deployments 画面で確認済み・2026-08-11）

```
Workers & Pages → hautecouturetherapist → 右上: 🦊 loutarma/HauteCoutureTherapist
```

| 送り先 | 起きること |
|---|---|
| **GitLab `main`** | **本番が差し替わる。** push が deploy そのもの |
| GitLab のそれ以外のブランチ | `<branch>.<project>.pages.dev` に**プレビューが1つ増える**（本番は変わらない） |
| **GitHub（どのブランチでも）** | **何も起きない。** Cloudflare は GitHub と繋がっていない。控え置き場 |

**Pages プロジェクト1つが繋がれるリポジトリは1つだけです。** GitHub と GitLab の両方を
配信元にすることはできません（プロジェクトを2つ作れば別サイトが2つできるだけ）。

この対応関係はコードのどこにも書かれておらず、Cloudflare の画面にしか無いので、
**記憶で判断しないこと。** 迷ったら Deployments 画面の右上を見る（ISSUE-061 の反省）。

### 「サロンの置き場」を使うための設定（1回だけ）

置き場の窓口は `functions/api/sync.js`（Cloudflare Pages の関数）で、R2 に置きます。

1. Cloudflare で **R2 バケット**を作る
2. Pages プロジェクトの Settings → Functions → **R2 バケットバインディング**で、変数名 `SALON_STORE` としてそのバケットを結びつける
3. アプリを **`https://<サイト>/#salon-key`** で開く →「はじめての設定」が出るので、決めた合言葉を入れて**値を出す**
4. その値を Cloudflare の環境変数 **`SECRET`**（Secret 型。以前の名前 `SALON_KEY` でも動く）に設定して、再デプロイする
5. 各端末で、同じ合言葉を入れる

**「はじめての設定」は、`#salon-key` を付けたときだけ出ます。** 置き場を用意する側の作業であって、セラピストがするものではないためです。ふだんの設定画面には合言葉の欄しか出ません。

**ビルド設定:** ビルドコマンドなし／出力ディレクトリ `product`。`functions/` はリポジトリ直下にあり、Pages が自動で拾います。関数は `functions/api/sync.js` の置き場所どおり `/api/sync` にだけ対応します。

**サーバーは中身を読めません。** 送る前にブラウザの中で暗号化します。合言葉から PBKDF2 で512ビットを作り、前半を暗号化の鍵（端末から出ない）、後半を認証用の値（サーバーへ送る）に使い分けています。後半から前半は割り出せないため、`SALON_KEY` と置き場の両方を握っても中身は読めません。

鍵づくりの塩は固定値です（URLを混ぜていません）。**引っ越して URL が変わっても、同じ合言葉で開けます。**

⚠️ **合言葉を忘れると、置いたものは誰にも読めません。** 復元する道はありません。

### なぜ Vercel から移したか

Vercel の Hobby プランは、規約で**個人・非商用の利用に限られています**。

> You shall only use the Services under a Hobby plan for your personal or non-commercial use.

さらに、予告なく停止できるとも書かれています。

> We may shut down and terminate projects or deployments using the Hobby plan without notice for any reason or no reason.

営業中のサロンのカルテが載る場所としては、この条件に預けたままにできません。Cloudflare は**無料プランでも商用利用が認められています**。

## 5. くらしの見立て（`/mitate/`・検証中）

星と、空と、食べたもの。その方の一日を、ひとつの物語として見立てる独立した画面です。
KARTE（顧客管理）とは別の画面で、KARTE のデータは読みません。

- **聞き取る → 今日の材料 → 見立てる** の3段。聞き取った内容と見立ては、その端末の中だけに残る（本名は聞かない）
- **今日の材料**：空と天気は毎朝の星詠み（`product/data/advice/today.json` の【0】）、季節・五行・旬は `product/mitate/seasons.js`
- **安全**：精油は KARTE と同じ `oil-safety.js` で先に絞る。食べ物のアレルギー・妊娠中の食の注意は依頼文の「守ること」に入れる
- **語り口**：占いのように楽しめて艶のある文。栄養やオーガニックの効き目など確かなことは、比喩に混ぜず正確に書く

### 見立ての作り方（2通り）

| 方法 | 動き | 費用 |
|---|---|---|
| **見立てを頼む**（検証中） | `/api/mitate` が Claude Code のルーティンを API トリガーで起動 → Claude が書いて `/api/mitate-result` へ届ける → 画面が受け取る（数分） | ルーティンの持ち主のサブスク枠 |
| **自分で Claude に渡す**（予備） | 依頼文をコピーして Claude を開き、貼って送る | 使う人のサブスク枠 |

- ルーティンへの指示書：`scripts/mitate/ROUTINE.md`（語り口や決まりを直すときはここ）
- 設定の手順（ルーティン・Cloudflare の変数・Zero Trust の例外）：`management/10_Operations/くらしの見立ての自動化.md`

> **規約について（大事）**
> 「見立てを頼む」は、いまは **Lou さんのサブスクで、Lou さん本人だけが検証で使う**前提です。
> Claude Code の規約は、開発者が**ほかの利用者の代わりに** Pro・Max の資格で処理を回すことを認めていません。
> **セラピストに使ってもらう前に、「自分で Claude に渡す」か、従量課金の API キーに切り替えること。**
> （[Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)）
