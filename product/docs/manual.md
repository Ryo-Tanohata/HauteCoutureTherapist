# Terre Mer KARTE 取扱説明書

サロンのカルテと予約を、ひとつにまとめて持ち歩くためのアプリです。

このページだけで、ひととおり分かるように書いてあります。
**「こういうときは、どうするか」から引ける形**にしてあるので、
上から順に読まなくても構いません。

**アプリの中の「📖 使い方」ボタンからも、いつでもここへ来られます。**
また、右下の吹き出しから、この説明書の中身をそのまま調べられます。

## 0. まず、大きな仕組み

覚えることは3つだけです。

### ① 画面は6つ

| | 何をするところ |
|---|---|
| 👥 **顧客一覧** | お客様を探す・登録する・カルテを開く |
| 📅 **カレンダー** | いつ誰が来るか。予約を入れる |
| ⚙️ **設定** | つなぐ・控えを取る・見た目を決める |
| ✨ **星詠みメッセージ** | その日のメッセージ |
| 🌿 **星とアロマ** | 色と星とアロマの対応表（見立ての参考） |
| 📖 **使い方** | この説明書 |

### ② 予約とカルテは、同じものです

**別々に入力する必要はありません。**

アプリの中では、予約もカルテも**同じ1件の記録**です。違うのは日付だけ。

| | 呼び方 |
|---|---|
| これから先の日 | **予約** |
| 今日・過ぎた日 | **カルテ** |

予約のときに入れた時間や施術内容は、**そのままカルテの一部として残ります。**
施術のあとで 🌸 訴えと、🐬 施術ごとの金額・メモ・写真を書き足せば、カルテとして仕上がります。

### ③ 書けば、勝手に他の端末へ届きます

保存するたびに、サロンの置き場を通じて他の端末へ伝わります。
**「送る」ボタンを押す必要はありません。**（[5. 端末をまたぐ](#5-端末をまたぐ)）

## 1. 最初にすること

### 1-1. サロンの置き場につなぐ

これをしないと、その端末の中だけで完結してしまい、他の端末と揃いません。

1. **⚙️ 設定** を開く
2. **合言葉**の欄に、サロンで決めた合言葉を入れる（**12文字以上**）
3. つなぐボタンを押す

つながると、置き場にあるものが降りてきます。

> **はじめて開くときは、先にメールの確認があります。**
> アプリの前に「メールアドレスを入れる画面」が出たら、登録してあるアドレスを入れ、
> 届いた数字を入れてください。1か月ほどは、その端末で入り直さずに使えます。

> **合言葉は、サロンで1つだけ決めます。**
> すべての端末で**同じ合言葉**を使ってください。違う合言葉は、
> 違う置き場につながっているのと同じで、まったく揃いません。

> **合言葉を忘れると、置いてあるものは誰にも読めません。**
> 開発した側にも読めません。取り戻す道はないので、**必ず控えておいてください。**

### 1-2. 2台目・3台目

やることは1台目と同じです。**同じ合言葉**を入れるだけ。

台数の上限はありません。パソコン・スマホ・タブレットを混ぜても構いません。

### 1-3. ホーム画面に置く（スマホ）

毎回ブラウザから開くのは手間なので、ホーム画面に置いておくと楽です。

| | やり方 |
|---|---|
| **iPhone** | Safari で開く → 下の「共有」→「ホーム画面に追加」 |
| **Android** | Chrome で開く → 右上の「⋮」→「ホーム画面に追加」 |

置くと、サロンの絵がアイコンになり、ふつうのアプリのように開きます。

> **ホーム画面から開いたアプリと、Safari で開いたページは、別の端末のように扱われます。**
> ホーム画面に置いたら、**そのアプリの中で**合言葉を入れてつないでください。
> **DuckDuckGo** で使うときは、このサイトを「**ファイアプルーフ**」にしてください。
> しないと 🔥 のたびに、合言葉も書いたものも端末から消えます。

### 1-4. 名前の出し方を決める（任意）

**⚙️ 設定** →「**📝 記録の設定**」を開くと、「一覧に出す呼び名」があります。
**ニックネーム優先／氏名優先**を選べます。

- **ニックネーム優先**（初期設定）… カレンダーや一覧に「はなちゃん」と出る
- **氏名優先** … 「山田 花子」と出る

ニックネームを入れていないお客様は、どちらを選んでも氏名で出ます。

## 2. こういうときは

日々の流れに沿って並べてあります。
見出しの下に「**▶ 動画で見る**」があるところは、押すと**実際の画面が動く短い動画**が、声と字幕つきで流れます。

### 2-1. 予約の電話が入った

1. **📅 カレンダー** を開く
2. その日付のマスを**押す**
3. カレンダーの上の「**🗓️＋ 予約・施術記録を追加**」を押すと、その日に入っている予約が出ます
4. 「**✍️ この日の記録を書く**」を押すと、記録を書く画面が開くので、
   - **お客様**を選ぶ
   - **時間**を選ぶ
   - 🐬 の「**＋ 施術を追加**」から施術を選ぶ（後で変えられます）
5. 「**記録する**」

これで予約が入りました。**カレンダーのマスに、そのお客様の札が出ます。**

> 施術・訴え・メモは、いま空でも構いません。施術のあとで書き足せます。
> お客様のカルテの 🗓️ から日付を押しても、同じ画面が開きます（お客様は選ばずに済みます）。

### 2-2. はじめてのお客様を登録する

1. **👥 顧客一覧** を開く
2. 「**＋ 顧客登録**」を押す
3. 入れるもの

| 欄 | 入れ方 |
|---|---|
| **顧客No.** | 次の番号が自動で入っています。**書き換えてもよい**（同じ番号はほかの方と重ねられません） |
| **氏名** | **必須**。これだけは必ず |
| **ニックネーム** | 任意。呼んでいる名前があれば |
| **よみがな** | 氏名を打つと自動で入ります。違っていれば直してください |
| **電話番号** | 任意 |
| **生年月日** | 星の見立てに使います |
| **紹介者** | 任意 |
| **Soul Color** | **1〜5色**。1色目がその方の色になり、カードとカレンダーに出ます |
| **初診の6枠** | Personal / Reason & Gole / 家族構成 / 病歴 / 薬 / memo |
| **特記事項・メモ** | 身体の特徴、お茶の好みなど |

4. 「**登録する**」

> **初診の6枠は、あとからでも書けます。** 問診の途中で埋まらなくても、
> 「👤 お客様の情報」から書き足せます（→ [3-3](#3-3)）。

> **書きかけのまま画面の外を押しても、消えません。**
> 「まだ登録されていません。閉じますか？」と確かめます。「キャンセル」なら、そのまま続けられます。

### 2-3. 今日は誰が来るか見たい

**📅 カレンダー** を開いて、今日のマスを見てください。

- マスの中に、**名前の札**が最大2枚出ます
- 3人以上のときは「**他◯人**」とまとまります
- **マスを押すと、その日の全員が下に出ます**

同じ方が1日に何度も来るときは「**はなちゃん ×3**」のようにまとまります。

### 2-4. 施術の前に、前回どうだったか見たい

1. **👥 顧客一覧** でその方のカードを押す（または名前で検索）
2. カルテが開きます
3. **📋 タブ**に、来店ごとの記録が新しい順で並びます
4. 見たい回を押すと、訴え・メモ・色・区分ごとのカルテ・写真が開きます

**書いたものだけが出ます。** 空の欄は行ごと出ないので、書いてある回ほど濃く見えます。

**カレンダーからでも開けます。** 日付のマスを押して、下に出た一覧から
その方の行を押してください。**過ぎた日ならカルテ、これから先なら予約の内容**が開きます。

### 2-5. 施術の前に、組み立てを考えたい

**📋 タブ**を上から見てください。前回・前々回の訴えとメモが、そのまま並んでいます。
✨ タブには、その方の体質から絞り込んだ「⛔ 使わない精油」が出ます。

> **「下ごしらえ」（AIの組み立て案）は、いま使わない設定になっています。**
> 使いたいときは **⚙️ 設定 →「🤖 AI の設定」→「🍳 下ごしらえ」**を「使う」にして、
> 画面を読み込み直してください。生成AIのキーの登録も要ります。

### 2-6. 施術のあと、記録を書く

予約のときに作った記録を、そのまま開いて書き足します。**新しく作り直さないでください。**

1. カレンダー、または一覧からその記録を開く
2. 記録の下の「**✏️**」を押す
3. 開いた画面で「**編集を有効にする**」を押す
   （開いた直後は**読むだけ**です。ここを押してはじめて手が入ります）
4. 書き足す

| 欄 | 何を書くか |
|---|---|
| 🌸 **訴え** | その日、お客様が言ったこと |
| 🐬 **施術** | 「**＋ 施術を追加**」から選ぶ。施術ごとに1枚ずつカードができます |
| 　└ **金額** | 定価が入っています。**割引などは書き換えてください**（その日だけ。定価は変わりません） |
| 　└ **メモ** | その施術で気づいたこと。使った精油、圧、順番など |
| 　└ **📷 写真** | その施術の写真。押すと大きく見られます |
| **全体の気付き** | 施術をまたいだ気づき。次回への申し送り |
| **選んだ色** | 🌈 color を追加すると、下に出ます |

5. 「**記録する**」で保存する

> **合計は、施術カードの金額を足したものです。** 🐬 の下に出ます。
> 🐬 を長押しすると、この欄の説明が出ます。
> 書きかけのまま画面の外を押しても、確かめてから閉じます。

### 2-7. お客様に「前に使った精油は？」と聞かれた

カルテを開き、**📋 タブ**を上から見てください。
記録を押して開くと、🍀 item の欄に、その回にお渡ししたものが書いてあります。

急ぐときは、**顧客一覧の検索**で名前を打てば、すぐカードにたどり着けます。

### 2-8. しばらく来ていない方を探したい

**📋 タブ**の頭に、通算回数・最終施術日・平均ペースが出ます。
記録ごとにも「前回来店から◯日ぶり」が付くので、声をかける目安になります。

### 2-9. 今月いくらになったか見たい

カルテの **💴 金額**タブに、その方の合計が出ます。

### 2-10. もう来られなくなった方がいる

カルテを開き、**名前の行の右にある 📦** を押すと、通常の一覧から外れます。
**消えたわけではありません。** アーカイブから、いつでも戻せます。

**「削除」は、本当に要らないときだけ**にしてください。
削除すると、他の端末からも消えます。

### 2-11. 施術メニューを増やしたい

記録を書く画面の 🐬「**＋ 施術を追加**」を押し、横に出る「**⚙️ メニューを編集**」から足せます。
アイコン・名前・金額・開く書く欄の4つを決めます（→ [4-5](#4-5)）。

金額は「決まった額」「その都度」「持たない（記録だけ）」から選べます。

### 2-12. 使い方を人に教えたい

アプリの中の「**📖 使い方**」を押すと、
**画面が実際に動いて手順を見せてくれる**案内が入っています。

- 顧客の登録
- 問診の入れ方
- 予約の取り方
- カルテの見方
- 星詠みの使い方
- AIキーの登録

読むより早いので、新しく入った方にはこちらを勧めてください。

### 2-13. お客様の情報を直したい（名前・顧客No.・アレルギーなど）

1. カルテを開き、**名前**を押す（👤 お客様の情報が開きます）
2. 「**✏️ 編集する**」を押す … **全部の欄が、まとめて入力できる形**になります
3. 直す（顧客No.・電話・生年月日・Soul Color・体質・アレルギー・初診6枠・メモ）
4. 「**💾 保存する**」を押す … 上と、画面の下に貼りついた帯の2か所にあります

**保存するまでは、何も書き換わりません。** やめるときは「やめる」を押してください。
保存できなかったときは「保存しました」とは出ず、理由が出ます（→ [7-3](#7-3)）。

### 2-14. 開発者にサンプルを見せたい

**⚙️ 設定 →「💾 データの書き出し・読み込み」→「🧪 サンプル（C-0000）だけ書き出す」**。
顧客No. **C-0000** の方だけが入ったファイルができます。**ほかの方は1人も入りません。**
受け取った側は「📥 読み込む」で取り込めます。

## 3. 画面ごとの説明

### 3-1. 👥 顧客一覧

- **検索** … 名前・よみがな・顧客No. で絞れます
- **カード** … 枠の色は、その方の Soul Color の1色目
- **カードを押す** … カルテが開きます
- **＋ 顧客登録** … 新しい方を登録
- **アーカイブ** … 通常一覧から外した方を見る

### 3-2. 📅 カレンダー

- **◀ ▶** … 月を移動
- **マスの札** … その日に来る方（最大2枚。3人目から「他◯人」）
- **マスを押す** … その日の全員が下に出る
- **下の一覧の行を押す** … 未来なら**予約の内容**、過去なら**カルテ**
- **🗓️＋ 予約・施術記録を追加** → **✍️ この日の記録を書く** … その日の予約・記録を作る（→ [2-1](#2-1)）

> **スマホでは、札は姓だけ**で出ます。1マスが狭いためです。
> 全部の名前は、マスを押せば下に出ます。

### 3-3. 📋 カルテ（お客様の詳細）

**上の帯にタブが4つ。その人のことは、名前を押すと開きます。**

| タブ | 中身 |
|---|---|
| 📋 **カルテ** | 来店ごとの記録。**いちばん使うところ**。頭に通算回数・最終施術日・平均ペース |
| 🗓️ **カレンダー** | その方の来店だけを月表示 |
| 💴 **金額** | 同じ記録を、金額の側から |
| ✨ **星** | 色と星の見立て、使わない精油（セラピスト用の参考） |

**名前を押すと 👤 お客様の情報が開きます。**
氏名・顧客No.・電話・生年月日・Soul Color・初診6枠・体質・アレルギー・メモは、ここです。

> **開いた直後は読むだけです。** 体質・アレルギーのチェックも触れません。
> 直すときは「✏️ 編集する」→ 直す →「💾 保存する」です（→ [2-13](#2-13)）。

**📦 アーカイブ と 🗑️ 削除 は、名前の行の右側**にあります。

### 3-4. ✨ 星詠みメッセージ

上のタブで **今日・1週間・1か月・3か月・半年・1年** を切り替えます。

- **毎朝 5 時台に、自動で書き直されます。** 天体の位置を計算し、
  国立天文台の暦・天気と気圧・占星術の読みの傾向を**ウェブで調べてから**書いています
- いちばん上の「**【0. 今日の空と体調】**」に、空の出来事と、天気から見た体の状態が出ます
- 本文の下に「**🔎 参考にしたページ**」が出ます。気になれば元のページを確かめられます
- 体調のことは「〜しやすい」までです。**診断ではありません**

### 3-5. 🌿 星とアロマ

色・星・チャクラ・アロマの対応表です。見立ての参考にしてください。
**お客様のデータは使いません。** 読むだけの表です。

### 3-6. ⚙️ 設定

**設定の中は、たたまれた見出しに分かれています。**
「📝 記録の設定」「🤖 AI の設定」などは、**押して開かないと中が見えません。**
探しているものが無いときは、たたまれていないか見てください。

| | 何をするところ |
|---|---|
| **合言葉** | サロンの置き場につなぐ |
| **自動で同期** | 保存のたびに揃える（入れておくことを勧めます） |
| **📤 書き出す** | 控えをファイルに落とす（iPhone・iPad は「"ファイル"に保存」） |
| **📥 読み込む** | 控えのファイルから戻す |
| **🧪 サンプルだけ書き出す** | C-0000 の方だけのファイル（開発者に渡す用） |
| **一覧に出す呼び名** | ニックネーム優先／氏名優先 |
| **AIのキー** | 星詠みや操作ガイドで使う |
| **置き場に登録する値** | アドレスの最後に `#salon-key` を付けたときだけ出ます。Cloudflare の `SECRET` に入れる値（普段は触りません） |

## 4. カルテの中身

覚えることは1つです。**「その人のこと」と「その日のこと」は別**、ということだけ。

### 4-1. 2つの層

| | どこにあるか | 何が入るか |
|---|---|---|
| **その人のこと**<br>（変わらない） | 名前を押すと開く 👤 | 氏名・顧客No.・電話・生年月日・Soul Color・初診6枠・**体質・アレルギー**・メモ |
| **その日のこと**<br>（1回ごと） | 📋 の中の1件 | 来店日・時間・訴え・🐬 施術ごとの金額とメモと写真・全体の気付き・選んだ色 |

> **体質とアレルギーは飾りではありません。**
> ここに入れた内容が、✨ の「⛔ 使わない精油」にそのまま効きます。

### 4-2. その日のこと（1件の記録）

| 欄 | 意味 | 空でもよいか |
|---|---|---|
| **来店日** | **これで予約かカルテかが決まります** | ✕ |
| **時間** | 30分刻み。夜間ぶんもあります | ○ |
| 🌸 **訴え** | **お客様が言ったこと** | ○ |
| 🐬 **施術** | 何をした日か。**いくつでも足せます** | ○ |
| 　└ **金額** | 定価から始まり、その日だけ書き換えられます | ○ |
| 　└ **メモ** | **その施術で、あなたが気づいたこと** | ○ |
| 　└ **写真** | その施術の写真 | ○ |
| **全体の気付き** | 施術をまたいだ気づき・申し送り | ○ |
| **選んだ色** | その日の色。🌈 color を足すと出ます | ○ |

> 🌸 と 🐬 は分けて書いてください。
> **言われたことと、見て取ったことは別のもの**です。あとで読み返すときに効きます。

**カードには、書いたものだけが出ます。** 空の欄は行ごと出ません。

見出しには、足した施術が**アイコンと名前の対**で並びます（🫶 再診　⏱️ 延長）。
**4つ以上の日は、先頭3つと「ほか N」**になります。
**カードを押して開くと、「🐬 施術とメモ」に施術・金額・メモ・写真が対で並びます。**

### 4-3. 施術は 🐬 の中で選びます

**上に並んでいた施術の札は、なくなりました。** 施術は 🐬 の中の「**＋ 施術を追加**」から選びます。

- 選ぶと、**施術ごとにカードが1枚**できます（金額・メモ・📷 写真・× 外す）
- **金額は定価が入った状態**から始まります。書き換えるとその日だけの金額になり、
  「定価 40,000円から変更（今回だけ）」と出ます。**空にすると定価に戻ります**
- 金額がその都度のもの（item・講座・W.S・その他）は、空から入れます
- **合計**は、カードの金額を足したものです

| 施術 | 定価 |
|---|---|
| 🌱 初診 ／ 🫶 再診 | 各 15,000円 |
| 📅 月set | 40,000円 |
| ⏱️ 延長 | 2,500円 |
| 🦋 靈氣・月 ／ 🕊️ 靈氣・週 | 15,000 ／ 10,000円 |
| 🐾 A.C | 5,000円 |
| 🦄 counseling ／ 🤝 ボランティア | 0円 |
| 🍀 item ／ 📙 講座 ／ 📝 W.S ／ ✳️ その他 | その都度 |
| 📈 monitor ／ 🤙 TEL ／ 🌈 color | 金額なし（記録だけ） |

> **🌈 color を足したときだけ、下に「選んだ色」の欄が開きます。**
> 以前の記録で、施術の種類ごとの欄にメモや写真が入っているものは、そのまま出ます（消えていません）。

### 4-4. 画面に出ていない欄があります

**施術メニュー・🧪 処方・金額の欄は、画面から下ろしてあります。** 消したのではありません。

- **施術メニュー**は、🐬 で足した施術から入ります。**金額**は施術カードの合計です
- **🧪 処方**にあたる内容は、その施術カードの**メモ**に書きます
  （🍀 item のカードに「精油と比率、基材、希釈」を書く、など）

### 4-5. メニューを足す・直す

🐬「**＋ 施術を追加**」の横の「**⚙️ メニューを編集**」から。決めるのは4つです。

| | |
|---|---|
| アイコン | 絵文字ひとつ |
| 名前 | 例：ペア施術 |
| 金額 | 決まった額／その都度／持たない（記録だけ） |
| 開く書く欄 | いまの10個から選ぶ（欄なしも可） |

**足せるのは「押すもの」だけです。** 書く欄そのものは増やせません。
記録は内部の合言葉で書く欄を指しているので、欄を増やすというのは
「そこに書いたものの行き先を新しく作る」話になります。
「ペア施術」のように押すものを足したいだけなら、書く欄は 🫶 施術 を選べば足ります。

> **消しても、すでに書かれた記録は消えません。** これから選べなくなるだけです。

### Soul Color について

登録のときに1〜5色選びます。

- **1色目**がその方の色になり、**カードの枠とカレンダー**に出ます
- あとから変えられます（カルテの Soul Color 欄を押す）

## 5. 端末をまたぐ

### 5-1. どう動いているか

**保存するたびに、自動で揃います。** ボタンを押す必要はありません。

1. 置き場から、他の端末が書いたものを**読む**
2. 手元のものと**突き合わせる**
3. 置き場へ**書き戻す**

### 5-2. 2人が同時に書いたら

**欄ごとに見ています。**

| | パソコン | スマホ | 結果 |
|---|---|---|---|
| 違う欄 | 訴えを書く | メモを書く | **両方残ります** |
| 同じ欄 | 訴えを書く | 訴えを書く | 新しいほうが出て、**古いほうも残ります** |

同じ欄が食い違ったときは、カルテに
「**⚠ 別の端末でも書かれていました**」という箱が出ます。
中身を読んで、要らなければ押して消してください。

**黙って消えることはありません。**

### 5-3. 消したとき

削除は、他の端末にもきちんと伝わります。**消したものが復活することはありません。**

ただし、**消した端末が同期する前に別の端末が書き戻すと、
一瞬だけ置き場に戻って見えることがあります。** どちらかの端末が
もう一度同期すれば、消えた状態に戻ります。

### 5-4. つながっていないとき

電波が無くても、**アプリは使えます。** 書いたものは端末に残ります。
つながったときに、自動で揃います。

### 5-5. 気をつけること

- **端末の時計が大きくずれていると、新旧の判定が狂います。** 自動設定にしておいてください
- 写真をたくさん入れると、同期に時間がかかります
- **保存してから数秒待ってから閉じる**と確実です（手が止まって約6秒で送ります）
- 2台で**同じお客様をほぼ同時に**直すと、あとから保存したほうが残ります

## 6. 控えを取る

### 6-1. なぜ要るか

置き場が壊れたとき、残るのは**いま端末にあるぶんだけ**です。
悪意より、事故のほうがずっと起きやすいことです。

### 6-2. やり方

**⚙️ 設定 → 📤 書き出す**。ファイルが1つ落ちてきます。

**iPhone・iPad** では共有メニューが開くので、「**"ファイル"に保存**」を選んでください（AirDrop で Mac に送ることもできます）。
共有メニューを閉じて保存しなかったときは、控えを取った扱いになりません。

### 6-3. どれくらいの頻度で

**月に1回**を目安にしてください。
しばらく取っていないと、アプリのほうから声をかけます。

### 6-4. 置き場所に注意

**書き出したファイルは、暗号化されていません。そのまま読めます。**

- サロンのパソコンの中
- 鍵のかかる場所にある外付けの入れ物

**メールに添付して送る、共有フォルダに置く、といったことは避けてください。**

### 6-5. 戻し方

**⚙️ 設定 → 📥 読み込む** から、控えのファイルを選びます。

## 7. 困ったとき

### 7-1. 他の端末に反映されない

1. **⚙️ 設定**を開き、つながっているか確かめる
2. 合言葉が**他の端末と同じ**か確かめる（1文字違うだけで揃いません）
3. 電波を確かめる
4. それでも駄目なら、「**🔄 いま同期する**」を押す

### 7-2. 「置き場と通信できませんでした」「入口のログインが切れています」と出る

| 出た言葉 | どうする |
|---|---|
| **入口のログインが切れています** | ページを読み込み直し、メールに届く数字でログインし直す |
| **置き場と通信できませんでした（カルテ・PUT：…）** | 読み込み直してもう一度。**かっこの中**は、どこで止まったかの印です。続くときはそのまま知らせてください |
| **通信できませんでした** | 電波を確かめる |

一度だけなら、画面の切り替えなどで途切れただけのことが多いです（自動で1回やり直しています）。
**DuckDuckGo** では、このサイトを「**ファイアプルーフ**」にしてください（→ [1-3](#1-3)）。

### 7-3. 「保存できませんでした」と出る

端末の空きが足りないか、保存できない開き方（プライベートモードなど）をしています。
**画面は閉じずに残っているので、書いたものは消えていません。**
写真を減らすか、ふつうのタブで開き直してから、もう一度保存してください。

### 7-4. 「合言葉が違うようです」と出る

入れた合言葉が、置き場のものと違っています。
**大文字・小文字・全角半角**まで含めて、正確に入れてください。

### 7-5. 「置いてあるものを開けませんでした」と出る

合言葉が違っています。**合言葉を変えると、鍵も変わります。**
以前の合言葉で置いたものは、新しい合言葉では開きません。

### 7-6. 入力の途中で、画面が閉じてしまいそう

書きかけのまま画面の外を押すと「**保存されていません。閉じますか？**」と出ます。
**「キャンセル」を押せば、そのまま続けられます。** 閉じたいときだけ「OK」を押してください。

### 7-7. カレンダーの名前が小さすぎる

スマホの1マスは狭いため、名前が長いと字が縮みます。
**マスを押せば、下に読みやすい大きさで全員出ます。**

### 7-8. 金額が「未定」のまま

🐬 で施術を何も足していないか、**その都度の金額を入れ忘れています。**

item・講座・W.S・その他のカードは、金額が空から始まります。
空のままだと、合計に「**＋ 未入力**」と出ます。
入れ忘れを「無料」と見分けるための出し方です。

### 7-9. 昔の記録を開くと「前に入っていた金額」と出る

**施術ごとに金額を持つ前に書かれた記録**です（→ [4-3](#4-3)）。
そのときの金額をそのまま出しています。**触らなければ、その金額のまま残ります。**

施術カードの金額を触ったり、施術を足し外ししたりすると、カードの合計に変わります。

### 7-10. 「下ごしらえ」のボタンが見当たらない

**いまは使わない設定になっています。**（消したのではありません）
**⚙️ 設定 →「🤖 AI の設定」→「🍳 下ごしらえ」**を「使う」にして、
**画面を読み込み直す**と出てきます。

### 7-11. 星詠みが古い・出ない

星詠みは**毎朝 5 時台に自動で書き直されます**（→ [3-4](#3-4)）。
「更新サイクルを◯日過ぎています」と出るときは、その朝の自動更新が止まっています。
**開発者に知らせてください。** 画面の側で直すものはありません。

### 7-12. 画面が白いまま／ボタンが効かない

1. **一度閉じて、開き直す**
2. それでも駄目なら、**別のブラウザ**で開いてみる
3. 直らなければ、**そのまま知らせてください。** 心当たりのある変更を戻せます

> **その場でデータを消したり、入れ直したりしないでください。**
> 端末に残っているぶんが、いちばん確かな控えです。

### 7-13. 間違えて消してしまった

控えがあれば、**⚙️ 設定 → 📥 読み込む**で戻せます。
控えが無いと戻せません。だからこそ、控えを取っておいてください。

## 8. 安全のこと

### 預けたものは、預かる側にも読めません

置き場へ送る前に、**端末の中で暗号にしてから**送っています。
鍵は合言葉から作られ、**端末の外に出ません。**
サーバーを預かる側が中を見ようとしても、意味のない塊しか見えません。

体質・アレルギー・病歴は、漏れたときに取り返しがつかないためです。

### 入口にも鍵があります

アプリを開く前に、**登録したメールアドレスに届く数字**を入れる関門があります（Cloudflare Access）。
合言葉とは別の鍵なので、片方が漏れても、もう片方で止まります。

### 開発者に渡すのはサンプルだけ

開発者に見せるときは「🧪 サンプル（C-0000）だけ書き出す」を使います（→ [2-14](#2-14)）。
**サロンの合言葉は、開発者に伝えないでください。** 伝えなければ、置き場の中身は開発者にも読めません。

### 守れていないこと

正直にお伝えします。

- **端末そのものは守れていません。** 端末の中のカルテは、暗号化されていません。
  **端末に画面ロックをかけておいてください。** これがいちばん効きます
- **合言葉は端末に残しています。** 自動で同期するためです。
  端末を人に渡せば、その人は中身を見られます
- **合言葉を忘れると、置いてあるものは誰にも読めません**

### やってはいけないこと

- 合言葉を**メールやメッセージで送る**（口頭か、紙で渡してください）
- 書き出した控えを、**共有フォルダやメール添付**で扱う
- **公共のパソコン**で開く

## 9. 用語

| 言葉 | 意味 |
|---|---|
| **置き場** | 端末をまたいで中身を揃えるための、サロン専用の預け先 |
| **合言葉** | 置き場を開ける鍵。サロンで1つ。12文字以上 |
| **同期** | 置き場と手元を揃えること。保存のたびに自動で走る |
| **控え** | 書き出したファイル。事故のときに戻すためのもの |
| **Soul Color** | その方の色。1〜5色。1色目が代表 |
| **施術カード** | 🐬 の中の、施術1つぶんの枠。金額・メモ・写真を持つ |
| **区分** | 施術の種類。以前は区分ごとに書く欄があった（いまは 🌈 color の色の欄だけ） |
| **アーカイブ** | 通常一覧から外すこと。消えてはいない |

## 10. 覚えておいてほしい3つ

1. **予約とカルテは同じもの。** 予約に書き足せば、カルテになります
2. **保存すれば、勝手に他の端末へ届きます。** 送るボタンはありません
3. **月に1回、控えを取ってください。** これだけは代わりがききません
